## 1. CVM hook 装配可配置化（P2，本期核心）

认知虚拟机五阶段管线（60+ hook 模块）的装配从编译期静态快照升级为**配置可调 + 运行时可热更 + 可回滚**：

- **`hooks` 配置块**：`config.json` / `.rivet-config.json` 顶层新增 `hooks: { disabled, timeoutMs, slowMs }`；`RIVET_HOOKS_DISABLED` env（逗号分隔）优先且为启动级约束
- **管线运行时开关**：`RuntimeHookPipeline.setDisabledHookIds()` / `isEnabled()`——下一轮 turn 生效，getManifest 自动反映
- **config HMR 热更**（config-watcher）：TUI 交互模式下改配置即时生效；防抖 500ms；文件写坏 fail-closed 保留旧值（测试驱动发现并修复 loadConfig 坏 JSON 静默回落默认导致的 fail-open）；`RIVET_CONFIG_WATCH=0` 关闭
- **profile 分层**：`$RIVET_HOME/profiles/<name>.json` 命名配置覆盖块，作为加载链第 3.5 层（defaults→user→project→profile→sessionOverlay）；内置 `lean` profile（禁用 dream-distill/skill-distill/anchor-break-scout）；`--profile` flag / `RIVET_PROFILE` env 选择；删文件即回滚；profile 文件变更同样热更
- **CLI 命令**：`rivet config list-hooks`（config/env/effective 三面）/ `rivet config set-hook-disabled <id> [--enable]`
- 文档：`docs/config-hooks.md`
