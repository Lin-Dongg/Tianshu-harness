# v3.17.0 发布记录

> 日期：2026-09-10
> 上一版本：v3.16.1（2026-09-09）
> 性质：**稳定性大版**——模型接入（DeepSeek `deepseek-flash` / OpenCode Go）+ 工具管线与桌面端一系列根因修复。

## 新增

- **DeepSeek 新模型 `deepseek-flash`**（V4.1 线）：1M 上下文、384K 最大输出、**原生多模态（支持图像输入）**，定价与 v4-flash 同档；DeepSeek 默认模型调整为 `deepseek-v4-flash`（此前 v4-pro，据悉将于 9 月 14 日下线，仍暂可选）。
- **OpenCode Go 服务商预设**：内置 `opencode-go` / `opencode-go-anthropic` 两档，请求补齐 `x-opencode-session` 与专属 UA，推理强度（reasoning_effort）透传不再被能力表吞掉。
- **MCP 面板「项目授信」区块** + 配套 `/project/trust` 路由——未授信导致 MCP 列表为空时给出可见解释与一键授信入口。
- **TUI 欢迎页升级**：首启引导分层（P1-1/P2 提示区收拢）+ 动态问候语 + 主题语气层。
- **出站身份头收口**：连接探测 / 欢迎语 / 视觉校验统一携带 caller-identity。
- **fulfillment**：付费结果同步官网 + 永久会员限量 200。

## 修复（重点条目）

**工具管线与稳定性**

- **`ast_grep` 全仓扫描卡死根修**：新增文件准入护栏（>1MB / 含 NUL 二进制跳过）+ 兼容 `path` 单数别名（此前被静默忽略退化为全仓扫描，曾致进程 88% CPU / 4 小时卡死）；含语法错误的文件不再整文件跳过，AST 搜索可用并明确标注不完整。
- **`write_file` 写后挂起（21 分钟回合死锁）结案**：根因 LSP `ensure`/`initialize`/`rpc` 三层无超时且进程死亡不释放挂起请求；修复为 45s / 2s / 死亡拒绝三层上界（该加固已包含在本版本包内）。
- **工具管线纵深修复**：pre/post 阶段打点（stall 告警的 `last` 可指认"卡在哪个阶段"）+ job 长等待心跳（后台任务等待不再误报卡死）+ 同步段慢操作留痕（`[slow-sync-stage]`）。
- **worker 进程隔离（OOP）**：子进程退出丢弃未 flush 大 result 帧修复——此前对真实 session 从未成功；review 窄口径隔离可选用（`RIVET_WORKER_ISOLATION=review`）。

**Windows 桌面端**

- **覆盖安装修复**：NSIS 安装钩子两处路径/目标错配（等待逻辑从未生效，报 `better_sqlite3.node` 写入失败）+ `wmic` 失效兜底（sidecar 杀不掉锁文件致静默更新「没反应」）。
- **更新通道修复**：`latest.json` 的 `windows-x86_64` 条目被 mac 侧版本剪除导致断链，已按 release 上的 `.sig` 验签补回；平台剪除落 PENDING-PLATFORMS.txt 待办清单防复发。

**TUI**

- **Ctrl+C 退出修复**：agent 活跃时退出通道被 abort 分支吞掉，改为窗口判定优先（二次 Ctrl+C 可靠退出）。
- **默认主题回 `cobalt`**（cyberpunk 改可选主题）；行内代码独立配色（正文不再整屏染色）；赛博朋克 pink→冰蓝去红调。

**API / 连接**

- **Anthropic wire 折叠连续同角色消息**：严格兼容实现（AWS Bedrock 等）不再报 `roles must alternate` 400 假崩；官方 API 零行为差异。
- 委派 / 判据提取的会话 ID 下沉到各自会话（不再共用进程兜底）。

**桌面端**

- 展开态高速滚动跳动收口（测量结算延迟 + 实测高度持久化）；拖拽滚动条下行被弹回修复；timeline 组身份漂移（推理/工作组折叠不进去）根修。
- MCP 面板「当前项目」锚定打开的会话（不再按更新时间猜）。

**其他**

- `importFromClaude` 导入失败不再静默；MCP 列表空因可见化。
- sync-to-public 不再覆盖公开仓 README（社区内容自治）。

## 升级说明

- 从 **3.15.x / 3.16.x** 自动更新即可，无配置迁移。
- **DeepSeek 老用户**如需使用 `deepseek-flash`：本地模型列表是配置快照，不会自动新增——请在 **设置 → 服务商 → DeepSeek → 添加模型**，模型 id 填 `deepseek-flash`（上下文 1000000 / 最大输出 384000，勾选「支持视觉」）。新装 / 新连接用户无需操作。
