## 1. 社区 PR 收编与 issue #392

- **SSE 缺 `[DONE]` 宽容收尾**（收编 PR #393，`3ef33688c`，issue #390）：MiniMax-M3 大上下文会话合法结束时不发 `data: [DONE]`，原无条件 `IncompleteStreamError` 作废完整响应、重试同点失败。新增终态 finish_reason 集合：EOF 无 `[DONE]` 但收到过终态 finish_reason → 记 warning 正常收尾；无 finish_reason → 保持抛错（半截回答不冒充完整回答）
- **GitHub API 查版本国内代理竞速**（收编 PR #391，`a818528cb`，issue #365）：CLI/TUI 更新检查裸连 `api.github.com` 国内超时即静默失败。新增 ghproxy 系前缀代理与直连并发竞速（HEAD 探测 5s）、session 级胜出记忆、fail-open 回直连；用户显式配置镜像时跳过竞速
- **同一 provider 多 API Key 的余额查询**（issue #392，`dbbeaf73f` + `0ea95a386` + 收编 PR #395 增量 `f3954e9ae`）：`/config/balance`、`/config/deepseek/summary`、`/config/deepseek/cost` 三条路由接受 `?provider=&keyId=`——显式 keyId 走该 key 的三槽凭据（与请求链路同一条解析链）；省略时顶层槽优先、落空回退池默认 key（修掉多 key 迁移后顶层全空恒查不到）；未知 provider/keyId 返回 400 不串号；响应回显命中账户的 keyId/label。桌面端 Insights 的 DeepSeek 账户卡在多 key 且未平台登录时提供 key 选择器，分别查看各 key 余额与月成本
- **CLI 跨平台生命周期与问答/计划预览修复**（收编 PR #389，`ede7a4635`）：CLI、agent/API、sidecar 与 VS Code 扩展的生命周期和状态隔离修复
- package-lock 顶层版本与 package.json 对齐（PR #395 附带件）；星域评测题库数据纳入公开仓同步（修公开仓 CI 的 domain-bank 守卫恒红）

## 升级注意

- **SSE 容错变化**：上游结束流时不发 `[DONE]` 但已带终态 finish_reason 的响应，现在会被正常接收而不是报「incomplete stream」——此前这类会话每轮必败，升级后表现为「突然能用了」
- **账户查询接口新增字段**：`/config/balance` 等三条路由的响应在池形态下新增 `keyId`/`label`（纯增量，旧客户端不受影响）
- **余额按 key 查**：多 key 用户在 Insights 的 DeepSeek 账户卡切换 key 查看各自余额；平台网页登录态下仍以登录账户为准
