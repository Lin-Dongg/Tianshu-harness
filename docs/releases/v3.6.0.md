## 1. DeepSeek 视觉模型预设：deepseek-v4-flash-vision-exp（`817830c0f`）

DeepSeek 官方新上线的视觉实验档接入模型预设：1M 上下文、最大 384K 输出、支持图像输入（截图看图），Json Output / Tool Calls / 前缀续写齐全（FIM 补全不支持）；定价与 `deepseek-v4-flash` 完全同档。图片按尺寸换算 token 计入计费。

### 如何配置使用

- **新安装用户**：装完即在模型列表里（桌面端 Settings 与 TUI `/model` 同源），选中即用。
- **升级用户**：磁盘已有配置时新预设不会自动注入（尊重已有模型列表）。两种方式启用：
  1. Settings / `/model` 里手动添加模型，模型 id 填 `deepseek-v4-flash-vision-exp`；
  2. 重走 `/connect` 连接流程——「为已有服务商添加模型」分支会默认勾选新预设。
- **API Key**：与 v4-pro / v4-flash 共用同一个 `DEEPSEEK_API_KEY`——已在用 DeepSeek 的用户无需重新配置，首次使用 DeepSeek 的用户配一次 key 即三个模型全部可用。
- **视觉能力**：模型声明 `supportsVision`，选中后 read_file 读图与 ask_image 自动放行图片输入，开箱即用。

### 附：官方口径

- 1M 上下文、输出上限 384K；思考模式支持非思考与思考（默认）
- 价格（每百万 tokens）：输入缓存命中空闲 0.05 / 高峰 0.10 元；输入缓存未命中空闲 1.5 / 高峰 3.0 元；输出空闲 4.5 / 高峰 9.0 元
- 高峰时段：北京时间周一至周五 9:00–12:00、14:00–18:00

## 3. worker 结果协议收口（`94d794a21` 起系列）

- failureReason 兜底归类接线修复：worker 崩溃/超时等失败不再一律盖 `unknown`，按错误消息归类为 timeout / worker_crash / json_parse 等 12 值——消费方可按失败语义差异化恢复（父取消 `caller_aborted` 不得重试、预算耗尽 `max_turns` 可续跑、熔断 `circuit_open` 应退避）
- 归类正则两轮收紧：裸 `signal` 词不再误判进程崩溃；网络层纯 AbortError 不再误标为「主动取消」（要求 abort/cancelled 伴随 caller/delegation/backoff 语境）——把可恢复的网络中断误标取消会压制恢复
- 子代理面板状态词汇统一：`passed` 与 `completed` 两个同义词收口为 `completed`，下游 UI 不再双判
- **子进程隔离 v1（`191222a89`）**：`RIVET_WORKER_ISOLATION=1` 时每次派发独立 worker 子进程（默认仍进程内）
