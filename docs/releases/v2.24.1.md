## 主题：Git Bash 探测加固——Windows 最终用户误判收口

CLI 单独发布的 patch 版本（桌面端保持 v2.24.0，两条产物线版本可分叉）。

### 1. Git Bash 探测补 2.5 路 `where bash` + Scoop 候选

Windows 上「未检测到 Git」警告的误报面收口：

- **Scoop 安装**——`~\scoop\shims` 是 shim 目录，原有的 `…\Git\bin\bash.exe`
  推导对它必然失败；新增 `%SCOOP%\apps\git\current\bin\bash.exe` 与
  `%USERPROFILE%\scoop\apps\git\current\bin\bash.exe` 两个候选
- **`bash.exe` 在 PATH 而 `git.exe` 不在**的自定义布局——新增 `where bash` 探针
- **WSL 硬性排除**——`where bash` 会命中 `C:\Windows\System32\bash.exe`
  （WSL 启动器），其 Linux 根 + `/mnt/c` 路径语义绝不可用作项目 shell

探测顺序（`src/platform.ts::resolveGitBashPath`）：
`RIVET_GIT_BASH_PATH` → `where git` 推导 → `where bash`（排除 WSL）→
常规安装位 / Scoop 候选 → 桌面端自带 PortableGit。

沙箱/VDI 环境（宿主 Git 被虚拟化抹掉）属真实缺失而非误判，指引不变：
`RIVET_GIT_BASH_PATH` 手动指路，或沙箱内安装 Git for Windows。
