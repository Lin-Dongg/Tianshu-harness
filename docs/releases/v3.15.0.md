# v3.15.0 发布记录（稳定基线版）

> 日期：2026-09-06
> 基线：**v3.9.0**（2026-08-29，`ef7c8315e`）
> 性质：**稳定基线回退版**——代码基线为 v3.9.0，仅版本号推进到 3.15.0 以接管更新链。

## 为什么有一个"内容更旧、版本更新"的 3.15.0

**v3.10–v3.14 的前缀缓存出现不稳定**（会话命中率异常下降、缓存反复碎裂），叠加滚动跟随、
写工具挂起等稳定性问题集中出现在这个区间。为保证可用性，本版**回退到稳定的 v3.9.0 基线**：
升级到 3.15.0 后即回到 3.9 的行为基线，缓存与整体行为恢复稳定；缓存问题的根因修复已在进行，
后续版本将在验证通过后重新带入 3.10+ 的能力（手机遥控、滚动换代、跨盘授权修复等）。

## 相比 3.9.0 的变化

仅版本号与发版物料（六点位 3.15.0 + 本记录）。无任何代码改动。

## 已知取舍（回到 3.9 基线意味着没有 3.10+ 的修复）

- Linux AppImage 无中文输入法修复（3.13 引入，issue #55）
- 滚动跟随行为回到 3.9 形态（issue #54 的换代修复不在此基线）
- 无 Termux 适配、无手机遥控、无跨盘授权链修复、无写工具挂起修复
- 前缀缓存为 3.9 形态（无 worker 冻结快照继承等 3.14 根修）

## 📦 安装

| 平台 | 资产 |
|---|---|
| macOS Apple Silicon | `Tianshu_3.15.0_aarch64.dmg` |
| macOS Intel | `Tianshu_3.15.0_x64.dmg` |
