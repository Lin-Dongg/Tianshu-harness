## 1. 星河 Galaxy 集群 —— 从概念验证到生产就绪

v2.26 引入的星河 MoE 多维派发在 v2.27 完成了四波收编，从"能跑"演进为"可信"。

### Wave 1：quorum 一等聚合策略

不再是一个 worker 说了算。quorum 达成时聚合共识；未达成时 galaxy tool result 标记 `isError`，从展示层到判定层全链路断层保护。修复了 quorumK 公式中 `ceil` 残留导致的 2 副本单证据放行漏洞。

### Wave 2：批级共享信息素 + 调度亲和 + 路由学习

同 authority 连续请求的缓存命中率实测 **99.2%**（跨 authority 归零——这是前缀缓存的硬边界）。调度亲和从 tie-breaker 升级为一级排序因子。路由学习闭环记录每次派发的 authority→model 实际命中情况，驱动后续调度的自优化。

### Wave 3：DAG 条件依赖边

`dependsOn` 从简单的下标数组升级为条件边对象：`{ index, onFailure: skip|alternate, alternateOrderId }`。team 的 markdown 计划解析器同步支持条件依赖语法，星河的 DAG 不再扁平。

### Wave 4：文件重叠显式报告 + 模型回退可见

当两个维度的文件范围存在交集时，星河不再静默——显式报告重叠区域，让调用方知情决策。`tierFloor` 参数暴露到调用层；worker 实际使用的模型发生回退时，结果中可见回退轨迹。

### Starflow 星流五阶段编排器

全新 `/starflow` 命令——council 评审 → team 波次 → galaxy 攻坚，三段中间设硬门禁：评审未执行/被否决、波次失败、攻坚未通过都会 `blocked` 停止并给出人话解释。状态持久化到 `.rivet/starflow/` 支持 resume 续跑。底层用状态机替代了此前的纯 prompt 注入串联。

桌面端 PlusMenu 同步补全了 scout + galaxy + starflow 协同编排入口，带分组标识。

### 相关修复

- `headless` 常驻 coordinator + galaxy 注册时序修复——消除空转等待
- `bootstrap` 包装转发 `onWorkerSettled`——星域位置注释漂移修复
- `council` 渲染层容忍 worker 缺字段输出——`.slice` 防护
- 审查预算放宽：廉价模型给足轮次和时间

## 2. Worker 结果契约 —— B 终轮 + D+C 改造

三份契约一次性落地：

**B 终轮定型**：每个 worker 的报告统一经过带历史上下文的**无工具收尾轮**产出。此前 worker 在执行最后一轮时可能被工具调用打断，导致报告不完整或格式不一致。终轮确保所有 worker 以干净的文本总结收尾。

**D 契约 — parseErrorKind 度量细分**：错误不再只是"成功/失败"。新增结构化错误分类（语法错、类型错、超时、截断、审查不通过等），让上游编排器可以按错误类型做差异化处理。

**C 契约 — changedFiles + verification 系统捕获**：worker 自动报告修改了哪些文件、跑了什么验证命令、验证结果如何——不再依赖 worker 的自觉声明。

**截断修复**：Strategy 6 JSON 截断修复补全字符串闭合与括号嵌套序；截断的 worker 报告不再被静默补全成 `passed`。

## 3. D8 计划约束自动注入

让计划文档里的约束真正生效——而不是写了就忘。

- **plan-constraints 提取器**：从 `.rivet/plans/*.md` 解析反目标（anti-goals）与待验证假设（unverified assumptions）

- **coordinator / loop / task-contract 全链路接线**：计划约束自动成为 worker 工单的 `constraints` 字段，不经人工中转

## 4. 前缀缓存 & Prewarm 性能

**批级共享 PrewarmCache（P0）**：`delegateBatch` 派发前对同批所有 worker 共享的 system prompt 前缀做一次预热请求，同批 worker 全部受益——首轮即命中，消除冷启动。

**star-domain 块移至 frozen 末尾（P1）**：星域提示词块从 system prompt 中间移至冻结段末尾（紧邻对话消息前），与 galaxy 回传块对齐——减少冻结段内的非确定性字节扰动。

**Meridian 后台全量索引**：代码库索引转为后台常驻任务，索引结果双路接入 PrewarmCache + physarum 预测，进一步提升缓存命中。

**compact 按 provider 分叉**：1M 上下文窗口的 LLM 压缩阶梯不再一刀切——DeepSeek 抬到 75%/85%，其他 provider 保持原有阶梯。

## 11. 团队模式：子代理协同工作流

v2.27 在 v2.26 的子代理基础设施之上，建成了完整的团队协同编排体系——不再是"调一个 worker 帮忙"，而是"组一支团队协同作战"。

### 三大协同模式

| 模式 | 命令 | 适用场景 | 核心机制 |
|------|------|---------|---------|
| **Scout 侦察** | `/scout` | 新项目摸底、全面体检 | 按关注维度并行派发多个只读 code_scout，汇总核对清单；诊断结论按规模自动分流—中小修复走 plan_task 计划链，大型多维改造映射为 starflow draftItems 走五阶段编排 |
| **Starflow 星流** | `/starflow` | 复杂工程任务需评审把关 | council 评审（产出密封契约 planJson）→ team 波次（契约执行）→ galaxy 攻坚（维度并行），三段中间设硬门禁，状态落盘支持 resume 续跑 |
| **Galaxy 星河** | `/galaxy` | 多维度并行分析/实现 | MoE 多维派发，quorum 聚合共识，DAG 条件依赖边，批级共享信息素 |

### cancel-rest 短路

`delegate_batch` 添加聚合策略——`all_required` / `first_success` / `majority` / `primary_decides` / `weighted_confidence`。策略达标后自动取消剩余兄弟 worker，节省 token。`team_orchestrate` 的跨波依赖断裂（W1 scout 完成后 W2 patcher 被误判为依赖未满足）已修复。

### D8 计划约束自动注入

`plan_task` 生成的工单自动携带计划文档中的反目标（anti-goals）与待验证假设（unverified assumptions）——计划里写的约束不再需要人工中转，全链路自动接线到 worker。

## 12. 工作区外授权闭环

工作区外路径审批从"每次都要问"升级为"记住一次、本工作区永久生效"。

- **`/grant` 斜杠命令**：`/grant <path> [read|write]` 写 per-workspace 存储即时生效，无参列出已记住授权
- **审批「批准并记住此目录」**：TUI 审批选项新增记住选项（`r` 直达键），桌面端同步复选框
- **`revokeGrant` + `listPersistedGrants`**：撤销时同步清内存并重写持久化文件，即时生效不需重启
- **CLI 子命令**：`rivet config allow-dir/revoke-dir/list-dirs`，默认 per-workspace，`--all-projects` 写全局 config
- **桌面设置**：BehaviorPage 新增"本工作区已记住"列表 + 撤销按钮

安全边界：默认永不写全局（跨项目生效必须显式 `--all-projects`），`revokeGrant` 同步清内存不残留。

## 14. 工具链 & 基础设施

- **默认工具集改为 frontend**：新会话默认启用 `browser_debug` 等前端工具，不再需要手动配置。
- **首启强制配 key**：首次启动必须先配置 API key，保存前做联机校验，避免空 key 静默失败。
- **脚本迭代停滞检测器**：补盲"工具全成功但仍停滞"的循环模式——之前只有工具失败才触发收敛，现在停滞也会被检测。
- **runtime hook 超时护栏**：异步 hook 挂起时降级跳过 + 慢 hook 遥测上报——避免一个慢 hook 拖死整个管线。
- **收敛优化**：classifyActivityMode 全局累计改滑动窗口；1M 窗口收敛阈值 nLow 12→25。
- **Help 手册扩充**：5 tab 重组为 7 tab，新增 8 张卡片，团队与子代理卡片按场景/用法/预期重写。
- **轻量查询 token 验证脚本**：`scripts/verify-task-classification.ts` 用于诊断信息查询的 token 膨胀。
- **slash 命令中文化**：所有斜杠命令的补全描述全面中文化 + 加长。
