# v2.19.4 迭代记录

> 日期：2026-07-17

## 桌面端自动更新修复

### 1. Windows 更新失败修复（installMode）

- 修复 Windows 用户点「立即更新」后更新无法完成的问题。
- 根因：`plugins.updater.windows.installMode` 此前为 `basicUi`，updater 执行安装时不传静默/passive 参数（`config.rs::nsis_args()` 对 `basicUi` 返回空数组），导致 NSIS 安装器以完整交互向导启动并等待用户操作，而主进程已退出——用户若未注意到后台弹出的安装向导，更新就不会完成，重启后仍是旧版本并再次提示，形成死循环。
- 改为 `passive`（updater 默认值）：安装器带 `/P /R` 参数，弹只读进度条、装完自动重启，全程无需用户交互。

### 2. 发版脚本版本一致性闸门

- `build-macos-release.sh` / `build-windows-release.sh` 生成 `latest.json` 时新增校验：所有 platform 条目 url 里的版本号必须等于顶层 `version`，错配则报错退出。
- 防止「保留旧平台条目」导致顶层 version 与某平台 url 版本不一致（曾导致 macOS 死循环提示更新）。
