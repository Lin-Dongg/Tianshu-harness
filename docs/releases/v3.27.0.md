## 升级注意

- **默认外观有变**：默认主题改为品牌化中性灰阶 + 玉绿 accent，默认亮色为中性白；**主题不再内嵌壁纸**（壁纸改为预设库手动选用），旧配置里的「主题自带材质/壁纸」绑定行为随之改变；选高级壁纸主题时会清掉被遮蔽的残留预设
- **推理强度默认值**：默认档位提到 max，如不需要（成本/时延敏感）请在输入框动作行下调
- **上下文预算与 frozen anchors v2** 改变了可用输入口径与冻结前缀的装配时机：长会话的前缀缓存收益会随实际装配状态刷新，升级后首个会话可能出现一次缓存重建
- **恢复与隔离在执行侧带灰度开关**，默认状态以 `RIVET_*` 环境变量与配置为准；恢复台账会原子写检查点
- **updater**：3.26.x 继续使用旧 updater key（`8685a123d`）
- **macOS 未公证**：首次打开需 `xattr -cr /Applications/Tianshu.app`
