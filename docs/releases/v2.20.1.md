# v2.20.1 迭代记录

> 日期：2026-07-21

## 主题：桌面右栏范式重构（悬浮 HUD 卡片）· 审查拦截透出 · 遥测校准 · 发版工程加固

### 1. 桌面端：右栏范式重构——悬浮 HUD 卡片

- **窗口 chrome 簇提取**（7f88f866）：`WindowChromeCluster` 共享组件——面板开关 + 收纳菜单 + Windows min/max/close，在 header 与右栏顶栏间互斥渲染，始终贴窗口右缘。
- **悬浮 HUD 卡片默认范式**（d4e8d2b6）：右栏默认不再是常驻侧边面板，而是会话区右上悬浮的实时摘要卡（变更统计/任务进度/子代理/后台任务，数据与 Changes 页同源）；点行经 `requestReviewTab` 展开侧栏落到对应页；absolute 锚定 conversation 列，侧栏开合自动贴边。ReviewPanel 菜单层移除，tab 行集提取为 `useReviewTabDefs` 双端共享。
- **卡片 v2**（0727a2f7）：Git 工具区收编（更改/提交或推送，header 的 Git 快捷钮与 HeaderGitMenu 删除，消灭双入口）；进程区内联待办清单；默认始终展开，手动收起成摘要细条并记忆；右栏叠加 surface 门控——首页等非会话页不再出现空侧栏，离开自动收起、回来恢复且不回写用户面板偏好；`reviewVisible` 存档位升 v3，老用户一次性回落卡片优先新默认。
- **导航补全**（9922dae0）：Tasks 行恒在（空会话也能进 Tasks 页看计划文档）；「涉及文件」区上浮卡片，点击经 `requestRevealFile` 落 Files 页定位。

### 2. 审查拦截透出（delegation / TUI）

- **三类透出**（7cf506eb）：审查拦截 rejected 改为 completed + failureReason——委派节点不再挂在 rejected 假死态。
- **TUI 端 ⚠️ 透出**（ab36062e）：completed 进终态集合 + failureReason 透传，审查拦截在 TUI 可见。
