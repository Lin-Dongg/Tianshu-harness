# v3.23.1 发布记录

> 日期：2026-09-19
> 上一版本：v3.22.0（2026-09-18）。v3.23.0 的 npm 包因打包缺陷作废（幽灵依赖声明进 dependencies 后被 tsup 默认 external 化，`zod-to-json-schema` 裸导入未随包分发，worker 路径必崩；已由打包门禁拦下，桌面资产从未发出）——请直接使用 3.23.1。
> 性质：**改名版 + 修复版**——npm 包更名为 `tianshu-harness`（与公开仓同名）；TUI 推理区/工具动态区一轮对标优化；安全加固（终端转义注入防护 + 路由路径穿越封堵）；LSP 语言支持与可靠性修复。

- **桌面端 Pro 订阅暂时无法支付**：应用内支付通道暂未开放，请前往**官网**完成支付；目前 Pro 开通/换绑**只能人工处理**，带来不便敬请谅解。

## 改名：tianshu-tui → tianshu-harness

npm 包更名为 [`tianshu-harness`](https://www.npmjs.com/package/tianshu-harness)，与公开仓 `github.com/huiliyi37/Tianshu-harness` 同名。新装：

```bash
npm install -g tianshu-harness
```

- 命令名 `rivet` 不变，新增 `tianshu` 别名（同一入口）。
- 旧包 `tianshu-tui` 停止更新并标记 deprecate；旧安装的版本探测与 `/update` 在新版内做了双名兼容，过渡期不失效。
- 产品早已不只是 TUI（桌面端 / VS Code 插件 / headless / sidecar），harness 是更准确的语义。

## TUI：推理区与工具动态区优化（grok-build / Claude Code 对标）

- **工具卡标题如实化**：未知工具（job / monitor / mcp__\* 等）不再显示光秃秃的「Tool」——用真实工具名（`mcp__server__tool` → `mcp·server:tool`）+ 通用参数摘要兜底，长跑任务一眼可辨。
- **thinking 提交后回看**：提交行带 `ctrl+t 回看` 提示，空闲时按 ctrl+t 把最近一次思考全文重印进 scrollback；收尾段 thinking 不再直接丢弃。
- **thinking 显示层降噪**：剥除 `**emphasis**` 标记（glob 双星 / dunder / 代码形态不剥）。
- **长跑无输出提示**：工具卡 ≥60s 无输出时显示「仍无输出 · Ctrl+C 可中断」。
- **spinner 相位如实化**：工具执行中显示真实工具标题，不再轮换思考系动词冒充模型活动。

## 安全

- **终端转义注入防护收口**：持久化文本（会话标题等）落盘前剥除 ANSI/OSC 序列；bash 危险命令识别加固——manual 档审批门激活 INJECTION 清单 + 归一化双视图判定（收编 PR #181 · zzuu080603；移植复核修掉兜底全剥导致的 scrollback 褪色回归）。
- **路由路径穿越封堵**：skill / plans / groupId / workerId 四处路由参数解码后加文件名包含性守卫（收编 PR #180 · zzuu080603）。

## LSP

- **语言支持扩展至 23 种**，languageId 接线修复，诊断触发面按 registry 判定。
- **非 TS 语言 LSP 修复**：didOpen/didChange 此前携带空文本导致非 TS 语言服务器全部失效；读不到内容时不再发 didOpen、不缓存 uri——「暂时读不到」不再固化成「永久空文档」。

## 桌面端

- **主题系统一致性收口**：主题循环序统一为单一来源（此前四处手写、长度不一，`light-classic` 在侧栏不可达）；跨窗口主题广播（主窗改主题，popout/browser 立即跟随）；外观页改造——主题搜索、跟随系统改为模式开关、纯色/玻璃材质预览。

## CLI / 服务端

- **外部进程会话发现**：同一 home 被多个进程同时 serve 时（桌面端 sidecar + 外部自起），外部新建的会话免重启可见（收编 PR #205）。
- **无头 `--stream-events` 接线**：旗标此前解析了但 sink 从未接上事件源。
- **bash 生命周期三修**：timeout 非正数按默认处理、兜底 SIGKILL 定时器必清、monitor 订阅失败回收孤儿 job（收编 PR #190）。
- **gitignore 匹配器**：补根锚定与 `**` 语义，树外守卫收窄（收编 PR #183）。
- **meridian 索引器 Windows 空转根修**：路径前缀守卫改 POSIX 归一后比较（收编 PR #191，同时是 #189 挂死根因）。
