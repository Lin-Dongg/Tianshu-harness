## 主题：星域钉定下沉 + TDD 死路豁免 + 审查预算缩放 + Windows 代理修复

### 1. 星域钉定逻辑下沉（所有入口统一）

根因：`defaultDomain` 钉定只在 TUI 入口 `main.ts` 一处，headless（`rivet -p`）及其他
外部调用入口完全漏钉。用户配置 `agent.defaultDomain: 'yaoguang'` 但会话实际落在天权。

修复：将钉定逻辑从 `main.ts` 下沉到 `AgentLoop.bindSessionDomain`，让所有入口
（TUI/headless/server/外部调用）在首条消息时统一检查 `defaultDomain` 配置：
- `defaultDomain` 非 `auto` → 直接钉定到对应星域
- `defaultDomain === 'auto'` → 走关键词路由（原有行为不变）
- 默认值 `'qiming'`（启明）——用户不配即钉定启明

相关文件：`src/agent/loop.ts`（bindSessionDomain）、`src/main.ts`（删除钉定块）、
`src/agent/loop-types.ts`（AgentConfig 新增 `defaultDomain` 字段）、
`src/agent/create-agent-config.ts`（透传 defaultDomain）。
新增回归测试 `src/agent/__tests__/domain-pinning.test.ts`。
已知问题文档：`docs/known-issues/2026-07-26-domain-pinning-only-in-tui-main.md`

### 2. TDD 死路检测豁免

dead-end-detector 的验证失败循环阈值从 2 次提到 3 次，并为测试文件
（`.test.` / `.spec.` / `__tests__` / `_test.` / `test_`）增加豁免——
测试文件 RED 是 TDD 预期行为，不计入死路循环。
`run_tests` 对测试文件的失败不再触发死路信号介入。

### 3. 审查 worker 预算按变更规模缩放

审查 worker 的 token 预算不再固定，改为按变更规模自适应缩放，
同时强化收敛 prompt 确保审查在预算内产出有效结论。

### 4. Windows 系统代理三处 bug 根治

`readWindowsSystemProxy` 三处 bug 修复，覆盖代理配置读取的异常路径。

### 5. 天权方向提示修复

去重相邻 turn 重复渲染天权方向提示，修正 high commit threshold 文案。
