## 功能更新

### 1. 星域图鉴 · 创世碑文

桌面端星域图谱新增「创世碑文」页——15 星域主星模型与碑文记录。瑶光补上 Fable 5 + 七杀创世记忆全本。TUI `/domain` 选择器改版：创始星 + 核心专长 + 创世碑文 tab + 缓存备注。

### 2. 桌面端体验

- **应用图标**：更换为小猫终端设计（天枢橘猫），Windows 图标改用圆角源
- **欢迎屏**：玻璃拟态重设计 + 交互式 ZCode 座舱 + 星域 prompt chips
- **会话正文字号下调**：长会话更紧凑可读
- **新建任务对话框防重复提交**：双击不再产生重复会话
- **安全加固**：redact 扩到裸密钥形态——sk- 族 / GitHub gh*_ / AWS AKIA
- **星域选择器失败兜底**：listDomains 挂掉降级内置表，不再整体隐藏/空白
- **输入框卡死修复**：worker feed 合并 text 项长度封顶——审查子代理返回大结果时不再冻结输入

### 3. 后台 Job 可视化

- `/jobs` overlay 完整键盘交互——↑↓ 选择、Enter 查看日志、x 停止
- job 事件接线：启动提示、完成通知、`/model` 切换存活
- jobs 双 map 终态封顶、选中按 id 稳定、SessionJobs.kill 终态返回 false
- 非搜索型 overlay 未消费键吞掉——不再幽灵进 composer

### 4. Agent 内核

- **子代理输出档 4096/8192→16384**：大报告不再顶格截断触发整轮续跑（v4-pro 实测对照）
- **读类工具豁免风暴折叠**：修掉「读→折→重读」循环
- **诊断态分流**：豁免只读惩罚链与产出停滞检测——诊断会话的大量读取不再被当停滞惩罚
- transient 判定从结果子串匹配改为 errorKind 结构化管道
- 收敛检测器 advisory 密度感知——advisory 洪水时不再投喂
- 天权/瑶光星域 advisory 降噪——预算从 3 降到 1；交叉验证纪律退回启明域
- 系统提醒 key 级冷却——readonly-spiral/turn-call-limit 3 轮间隔
- 指针占位符回吐优雅化解全覆盖（write/edit/hash-edit/plan）
- 语法错误回滚标记为 transient——收敛检测不再误判停滞
- 星域创始模型修正——瑶光 Fable 5 / 华盖 GPT-5.6-Sol / 启明+长庚 Gemini 3.6 Flash / 天梁 huiliyi37；长庚补 expertise 字段

### 5. TUI 端

- worker 身份拼法统一——主行/续行/侧栏不再两种写法
- digest 行带派发侧身份——多 worker 摘要不再匿名
- 子代理面板与校验消息英转中
- 内联舰队面板截断改显示宽度账——CJK objective 不再常态折行
- 主题色视觉工学优化（降低视觉疲劳）
