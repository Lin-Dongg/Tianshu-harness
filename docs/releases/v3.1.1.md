# v3.1.1 发布记录

> 2026-08-10 · 补丁版本：桌面端稳定性与子代理预算修复（9 commits）

## 1. 桌面端稳定性（写文件卡死事故链修复）

- **会话忙碌提示修复**：发送消息时若会话正在执行中，改为明确提示"会话正在执行中，输入已保留可稍后重发"，不再显示容易误解的"发送失败"错误
- **sidecar 健康探测放宽**：探测间隔 2s→4s——写文件等操作引发的事件循环短暂停顿不再被误判为服务卡死而重启
- **工具结果提交窗口放宽**：abort 后的结果落盘等待 3s→6s，覆盖实测 4.4s 事件循环尖峰，减少"写入已确认但结果丢失"的中断恢复提示

## 2. 子代理预算与执行（长任务不再频繁超时）

- **写工单轮预算 300s→600s**（patcher/type_fixer 等 6 个写工档位），长 shard 的"实现+验证到绿"不再被墙钟切断
- **自动续跑上限 4→6 次**，partial 结果回收率提升
- **写工轮次预算 32→48**，多文件 shard 不再轮次撞顶
- **显式预算上限放宽**：单次派发最高 100 轮 / 45 分钟（此前 80 轮 / 30 分钟）
- **修复预算静默截断**：runtime 默认轮次 40→100，此前写工 48 轮预算被内部钳制为 40，放宽未生效
- **空跑标记**：预算充足却几乎不做工具调用的 worker 标记为"空跑"而非"没干完"，汇报口径更准确

## 3. 认知纪律

- **太一域新增"取证"纪律**：直接观察（相邻行/时间戳/磁盘证据）优先于层层推断——诊断时先找可复核的观察，再让因果长出来

## 4. 兼容性

- 补丁版本，无破坏性变更；`tianshu-tui` CLI 与桌面端 runtime 同步升级
