## 1. 提示音通知（桌面端）

任务完成或有审批请求时，桌面端现在会播放提示音。完全独立于系统通知——可以关掉声音但保留弹窗，反之亦然。

**使用方式**：设置 → 行为 → 通知 → 声音提醒
- 5 个内置提示音：铃声 / 和弦 / 叮咚 / 轻柔 / 提醒
- 点击「试听」预览每个音效
- 支持自定义音频文件（mp3/wav/ogg）
- 提示音与 OS 通知在相同事件点触发（任务完成 / 审批请求 / 后台任务失败）

**配置项**（localStorage 持久化，无需手动编辑 config）：
- `soundEnabled`：开关（默认开启）
- `selectedSound`：选中的音效（默认 ding）
- `customSoundPath`：自定义音频文件路径

底层使用 Web Audio API 合成预设音效，零外部依赖。自定义音频通过 HTML5 Audio 播放。

## 3. 大图自动压缩（CLI + 桌面端）

超过 10MB 的图片不再被直接拒绝——桌面端自动三档压缩兜底：

1. 标准设置：长边 1568px，JPEG quality 0.82（覆盖 99% 场景）
2. 输出仍 >10MB：降 quality 到 0.55
3. 仍超限：降分辨率到 1024px + quality 0.55
4. 最终仍超限才报错

CLI 端同步将图片上限从 1.5MB/5MB 统一提到 10MB，对齐主流视觉 API 限制。通过系统工具（macOS sips / ImageMagick）处理。

## 4. `/scout` 巡天侦察蜂群

新增 `/scout` 斜杠命令——轻量并行只读诊断蜂群：

```
/scout <诊断目标> [--dims 前端,后端,集成]
```

- 先摸底项目结构，再按维度并行派发 code_scout worker
- 每个 scout 只读不写，产出带 evidenceKind/evidenceRefs 的可信度标注
- 最终交付实测核对清单 + runbook
- CLI `/scout` 和桌面端 PlusMenu → Scout 均已可用

CLI 端此前注册了执行逻辑但命令面板漏掉了展示条目——v2.26 已修复，`/` 搜索可匹配。

## 7. Team+Scout 证据管线

`/team` 自由任务执行前增加 terrain scout 摸底阶段：
- plan_task 前先跑 code_scout 做证据先行调研
- scout findings 带 evidenceKind（firsthand/inferred）和 evidenceRefs（file:line 锚点）
- 摸底结果喂给计划分解器，消除盲拆

所有并行 worker 的 prompt 强制产出 evidenceKind/evidenceRefs 标注，不再区分 `/scout` 或普通 delegate_batch。
