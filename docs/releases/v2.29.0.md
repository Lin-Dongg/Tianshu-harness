## 1. TUI 终端重塑 —— 自然流布局（本期最大工程，~20 提交）

终端消息流从「贴底重绘」改为**自然流**：消息从顶往下排、输入框跟随内容流、满屏后钉底不跳；首屏恢复自然流（欢迎屏正下方锚定），resume 会话同样生效。配套的滚动与擦写修复链：

- 期间布局改造曾整体还原（backup tag）后重做——最终以自然流形态收敛

## 10. 文档附件管线（word / excel / pdf）

Composer 端到端支持文档附件：粘贴与文件选择器放行 office/PDF，附件以 base64 送到 sidecar，服务端 `doc-extract`（pdftotext / textutil / soffice / exceljs）抽出文本后前置进 prompt——与图像走同一条「非文本附件转文本」通路。抽取失败降级为单条错误提示，不阻断整体发送；抽取结果带 EXTRACTION_CAVEAT 标注，模型不会把抽取文本误当原件版式。exceljs 随之从 optionalDependencies 提升为正式依赖（xlsx 抽取不再靠可选装成功）。

## 11. 桌面端配色与渲染成本（随桌面线发布）

- **去「灰蒙蒙」**：`data-theme="dark"` 那批深色玻璃与重阴影原本写成 `html[data-theme="dark"] X, X`，第二个裸选择器让深色样式成了**所有**主题的默认（含默认净白）。theme-loader 按 `colorScheme` 落 `data-scheme`，七个组件族改按 scheme 分派——这是整片界面发雾的主因
- **文字层级归位**：43 处 `var(--faint)` 逐处判定。它是色阶末档（净白对 `--bg` 仅 1.5:1），却被当「更淡的 muted」用在工具输出预览、任务摘要、时间分组这些必须读的文案上。两档收口：`--faint` 只留纯装饰，承载信息的文案下限为 `--muted`（净白 5.59:1 / 暗色 5.38:1，均过 AA），用点由守护测试的装饰白名单钉住
- **选中态与 hover 分离**（侧栏 nav / 会话行 / Mission·Plan 筛选器）；工具行补 ok/run 语义色
- **渲染成本**：pulse-running 从 box-shadow 动画改 `::after` 的 transform/opacity、glyph-breath 去 text-shadow 关键帧；去掉 width/max-width 的 transition（这三处每帧触发布局重算）；BrowserPanel 改窄订阅，隐藏期不再随文本 delta 唤醒
