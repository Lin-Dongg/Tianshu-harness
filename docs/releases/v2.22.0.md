### 1. 桌面端：会话滚动与输入光标根修

**滚动「拉不到底部 / 下拉回弹」根治**（54aa31ce）——此前修过 10+ 次未除根。本次定位三个结构性根因并全部拆除：

- thinking 状态条/审批卡显隐改变视口高度，把跟底静默顶开（主根因）→ 新增视口高度自愈：跟底激活时几何变化后自动重钉真底；
- 两处残留的全量行高重置路径导致滚动位置被浏览器钳位（下拉回弹）→ 改逐行确定性纠正；
- 回底写入统一走 DOM 真底，废除易与手势叠加产生回拨的库内 reconcile 循环；
- 配套取证探针增强 + 无头 Chrome 布局复算 harness（11/11 达标）+ 两条防回归铁律钉入测试。

**输入框「有概率指针乱跳 / 中文输入错位」根治**（2e9635a8）——草稿同步的 store 回声在提交窗口内把刚打的字回拨（IME 组词期直接打断输入法）；mention 剥离正则在输入中途突变受控值。回声判别 + 裸 token 只在空白边界剥离，中文连续输入不再错位。

### 2. TUI：IME 组词串锚定回输入框内（7a8f314b / 5a405169）

中文输入时组词串（拼音）此前跳显示在输入框下方屏幕底缘并随帧跳动——终端 IME 候选窗锚定的是硬件光标，而硬件光标一直停在状态行末尾。现每帧渲染结束把（默认隐藏的）硬件光标精确驻停到输入框光标处，组词串回到框内。后续修复关联的重复行问题：CPR 探针在输入框几何变化时的竞态误判（5a405169，rowsUp 漂移丢弃判定），该机制默认开启，`RIVET_TUI_HARDWARE_CURSOR=1` 可显示硬件光标。

### 3. 编辑器内核：Undo/Redo · 选区 · 长粘贴收纳

- **fish 式 Undo**（db42a552 / 6a4a50de）：连续输入按词合并为一单元、空格分界、中文连续输入合并；Ctrl+- / Ctrl+Z 撤销；提交即封存（上一条文本不会被下一条撤销复活）。
- **Redo**（096cf2dd）：Ctrl+Y 重做，与撤销同构的内存防护。
- **键盘选区 + 剪切/复制**（5c6023db）：Shift+方向/Home/End 反色选区；Backspace 删选区；Ctrl+K 剪切、Alt+W 复制、Alt+Y 回粘；OSC52 同步系统剪贴板（终端不支持时内部剪贴板兜底）。
- **长粘贴自动收纳**（096cf2dd）：超过 10 行或 1000 字符的粘贴折叠为 `[paste #N]` 标记（反色 pill、原子移动/删除），提交时自动展开还原——长计划/日志不再淹没输入框。
- **vim visual mode**（82446bf7）：`v` 字符选区、`V` 行选区，`d/c/y/x/o/p/P` 操作符闭环，`-- VISUAL --` 模式标签。
- **历史草稿**：上翻历史不再丢失在输草稿，下翻恢复（db42a552）。
- **Ctrl+R 历史搜索**：换用评分排序（前缀/词命中加权），常用命令更好找（5c6023db）。

### 4. 语义与提示：@file 节点 · ghost text · 代码块高亮 · Contract 预览

- **@file 断链修复**（096cf2dd）：Tab 补全的文件现在产出规范的 `@file:` 引用（此前补全后提交不会被解析，静默失效）；Backspace 可整体删除引用节点；不存在的引用在输入框下方即时提示；提交时路径规范化为相对路径。
- **斜杠参数 ghost text**（38024774）：输入 `/effort ` 等命令后在光标后暗色提示可选参数（`off|low|medium|high|max`），继续输入即消失。
- **代码块高亮**（5c6023db）：输入中的 ``` 代码块暗色着色。
- **Mission Contract 预览**（cd8d5ca1）：含 @引用、#验收标签或长文本的提交先出确认卡（目标/范围/验收/规模一目了然，不存在的路径标黄），Enter 创建任务、e 返回编辑、Esc 取消；两三句话的短输入依旧直接发送零打扰。

### 5. 性能与稳定性加固

- **渲染帧率封顶 60fps**（11a333bb）：高频流式输出/整段上屏时渲染合并节流，CPU 只降不升；提交/补全等关键路径保持同步即时。
- **粘贴安全**：粘贴内容剥离终端控制序列，防转义注入（db42a552）。
- **输入卡死兜底**：半个转义序列滞留不再卡死后续按键（db42a552）。
- **undo 内存防护**：快照滞留总量上限，多次超大粘贴不胀内存（38024774）。
