## 升级注意

- **CLI 状态行形态变了**：老的密集徽章栏先换标签行、再收敛为符号化单行状态行（模型 ◎effort ⚡cache ◧ctx ¥cost + 余额角标），详细信息在 `/cache` 等面板
- **未授信项目的 `.rivet/knowledge/` 不再注入**：自己项目里依赖项目记忆/知识索引的，用 `/trust`（或 `--trust`）授信后恢复
- **压缩包可以直接拖进输入框**（zip/tar 系）：不再要求先解压；内容不占上下文，agent 按需自取
- **新会话默认推理档 high**：原来默认 max（桌面）/ medium（flash 预设）——显式设置过档位的会话与用户配置不受影响
- **`deepseek-v4-flash` 改名 `deepseek-flash`**：手写配置引用旧 id 的仍可调用（由 V4.1 Flash 承接），建议改用新 id
- **接入 Gemini**：`/connect` 或设置页选 Google Gemini 预设，粘贴 AI Studio 的 API Key 即用；`gemini-2.5-*` 已退役请选 3.x 档
- **GitHub MCP 启用**：推荐集成卡片点「启用」→ 填 OAuth Client ID 走浏览器授权；或自定义服务器 + headers 填 `Authorization: Bearer <PAT>`
- **MCP 工具描述变更会提示**：server 重拉时工具描述发生变化将要求重新审批（rug-pull 防线），属正常现象
- **TUI 渲染模式**：原生回滚为全平台默认，fullscreen 需显式选择
