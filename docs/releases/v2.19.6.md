# v2.19.6 迭代记录

> 日期：2026-07-19

## 主题：工程纪律闭环 · 工具装配减负 · 桌面端稳定性

### 1. DisciplineEligibility 资格分层（工程闭环收官）

- `isActionable` 布尔拆分为可组合资格对象（`deriveDisciplineEligibility`）：解释/分析/文档任务不再误触发 TDD、免疫提示、协作派发与重型认知投影；工程任务保持完整纪律。
- 全部消费方迁移完成（plan-advisor/collab/dispatcher/cognitive-ledger），三元回退移除，eligibility 成唯一事实源。
- 两个降级窗口补钉：空 taskKinds 安全网加问题信号次级触发（单文件 bug 报告不再漏工程纪律）；`noteEligibilityMissing` 让未接线消费点在 RIVET_DEBUG 下可观测。
- Wave 3：交付验证分层——非工程任务改文件不强制验证，eligibility 缺省 fail-closed。
- E2E 回归矩阵 10 输入锁定判别。

### 2. 工具装配三档 preset（入口成本 -23%）

- 实测主控每会话加载 44 个工具（60KB 定义，~17k tokens），原 "kernel ≤26" 预算只盯 default-registry，对 bootstrap 18 个失明。
- 新三档：**minimal（默认 30）/ frontend（31）/ full（44）**，会话启动期解析、会话内冻结（前缀缓存零破坏）。`RIVET_TOOL_PRESET` env 或 `tools.preset` 配置。
- 桌面端 Settings 新增「工具档位」配置项，可视化切换，新会话生效。
- kernel-budget 棘轮改为盯完整装配（minimal ≤ 32），增长必须写明理由。

### 3. typecheck 致盲事故根治

- bash 输出过滤器对管道命令洗白 exit code（`tsc | head` → exit 0 → 合成 "✓ typecheck passed"），曾导致 agent 凭虚假信号连续提交（incident-2026-07-19）。
- 修复三层：内容优先于 exit code（输出含失败签名按失败处理）；管道命令一律不过滤；tsc 诊断保留完整文件位置。40 例过滤器测试覆盖。

### 4. 桌面端

- **长会话行重叠根治**：虚拟列表从绝对定位改流式窗口（正常文档流 + 上下 spacer）+ 确定性行高清扫（resizeItem 直写，不依赖 WebView2 ResizeObserver）——重叠在结构上不可能。
- ContextRing 按模型分阈值：DeepSeek V4 1M 窗口 70% 预警 + ≤50% 日常建议。
- 版本更新缓存提示：更新后开新线程而非重连旧会话（前缀缓存碎片成本）。
- 议事会 surface 重铸为星域图谱；星域图谱画布尺寸与选中内容解耦。

### 5. 其他

- TDD gate suggest 接工具层实际动作：阈值提醒内联进编辑结果尾部（前缀缓存零影响）。
- 交付门禁 verify routes：按路径路由确定性检查，desktop/ 子项目盲区覆盖。
- office 三件套插件补强：excel 修 range bug + 公式 + xlsx_edit；pdf CJK 字体自动解析；ppt theme + pptx_read + 图表。各带 SKILL.md 与 smoke 测试。
- 提示词减负：删除"交给新会话"全部无条件出口（实测 ctx 10–20% 时模型反复建议交接）。
- 子代理终态即时化：worker 不再陪跑最慢兄弟。
- `.cursor/plans` 30 篇设计文档收编入库。
