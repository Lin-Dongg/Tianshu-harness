# v3.21.0 发布记录

> 日期：2026-09-16
> 上一版本：v3.20.0（2026-09-14）
> 性质：**功能版 + 一处破坏性变更**——会话工作区体系（issue #147）四层落地、MCP 稳定性修复链收口；同时**模型 alias（惯用短名）体系废弃**，模型一律按原 ID 保存与展示。

## ⚠️ 破坏性变更

**模型 alias 短名体系废弃（收编公开仓 PR #154）**

- **配置层**：`modelConfigSchema` 不再声明 `alias` 字段（zod 默认 strip——旧客户端传入不报错、不落盘）。存量配置加载时由新增的 `migrateStripModelAlias` 幂等剥除 `provider.models[]` 与 `keys[].models[]` 两层 alias，并按 id 去重后回写，历史数据自愈。
- **语义**：模型一律按原 ID 保存与展示；短名引用 fail-closed（**不再静默映射到同 provider 的另一个模型**）。这修掉了两个实际症状：① 保存语义破坏——探测列表只勾一个模型却落库整组预设（含旧残留与重复行）；② 展示错位——`/model` 选择器与状态栏显示短名，用户认不出自己保存的模型。
- **保留的容错层**：`src/api/model-aliases.ts` 维护一份同义表（48 条），继续服务**输入解析**（probe 回填把用户手输/聚合平台的短名归一到 canonical id、存量 `review.profiles` 里写的短名仍可解析）。表外的名字依旧 fail-closed，不做模糊匹配。这两层同源但消费面不同：一个面向存储与展示，一个面向输入容错。

## 重点新能力

**会话工作区体系（issue #147，四层贯通）**

- **配置层**：新增 `workspace` 配置段——默认工作区 + 临时会话隔离根。
- **服务端**：会话工作区解析与 `/config/workspace` 路由；该路由为部分更新语义（单字段提交不再清掉另一字段）；`config-default` 目录无效时回落——不落无效位置、不谎报来源。
- **桌面端**：新建会话的默认工作区选择 / 临时会话入口；工作区回退不再静默，读取失败与未配置分开提示。
- **子 Agent**：工作区判定规则与明示——失败路径（isError 与抛错）也带 `[workdir:]` 前缀，Agent 侧不再靠猜。

**账号授权绑定体系**

- 账号 device flow 路由上 sidecar；授权链接补 code + 单次检查原语。

**MCP 稳定性修复链**

- **stdio 传输退出后自动重连**（issue #148），崩溃可诊断。
- 启动失败分类拆细（issue #149）+ 预设启动冒烟用例。
- 预设改官方端点 + PATH 兜底加固（issue #150）。
- **PATHEXT 剔除脚本宿主扩展**（#149 根因 B）——CWD 里的同名 `.js` 不再拦下 npx 的 `.cmd` shim。

## 性能

- **文本粘贴不再无条件读剪贴板图片**：macOS 上无原生读图包时读剪贴板会 spawn osascript（实测中位 422ms），旧实现让每次普通文本粘贴都白等约 0.5s。改为只在粘贴内容带二进制解码残渣（U+FFFD / C1 控制符 / 孤立代理 / 私用区）时才读——端到端实测 512ms → 5ms。
- 意图路由等待与 worktree 检测并行：`initializeRun` 总等待从 sum 降为 max。
- 会话列表缓存改增量 upsert：append 路径不再打掉整表缓存。
- 桌面安装包图片资源无损压缩：61 个文件节省约 1.26MB（来源 PR #1 · liuwanwan1）。
