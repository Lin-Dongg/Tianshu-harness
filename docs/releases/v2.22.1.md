### 1. CC Switch provider（社区贡献 PR #8）

新增 `ccswitch` provider——本地 OpenAI 兼容代理（CC Switch），支持通过 cc-switch 中转使用多种模型。

- 6 个预设模型：claude-opus-4-8 / claude-sonnet-4-5 / deepseek-v4-pro / glm-5.2 / gpt-5.6-sol / gpt-5.5
- 认证：`CC_SWITCH_PROXY_API_KEY` 环境变量，默认端点 `http://127.0.0.1:8891/v1`
- cacheType=none, thinking=disabled, effortFormat=reasoning_effort（透传到后端模型）
- 全链路：provider-registry / provider-profile / WELL_KNOWN_DEFAULTS / provider-presets / default config
- config loader backfill：provider name 从 map key 自动补全（含 null 安全防护）

贡献者：[@qiaodier](https://github.com/qiaodier)（Co-authored-by 已标注）

### 2. web 整站抓取（web_crawl / web_map）

- **web_crawl**：整站爬取，含 robots.txt 遵守、深度控制、并发限制
- **web_map**：站点地图生成，支持 sitemap.xml 解析 + 链接发现
- web-fetch 抓取内核抽取（fetch-core），供 crawl/map 复用

### 3. web-fetch 三级降级 + actions 体系

- **Playwright 本地渲染三级降级**：桌面端内置 chromium，解决国内 SPA 抓取错误页
- **B1 maxAge 缓存**：「缓存即引擎」语义，命中不再发起请求
- **B2 actions 体系**：渲染页内交互（登录墙 / 无限滚动通用解法）
- **firecrawl A 级质量包**：转换管线黑名单 / 图片链接修复 + 成功判定规则 + 渲染选项

### 4. 桌面端体验闭环

- 收件箱 / 新建会话 / 星域选择器优化 + 气场渐变调色系统
- 会话悬浮栏与方案审批卡片 UI/UX 重构美化
- 会话标题自动重命名失效修复 + 三处会话菜单深化联动

### 5. Windows 安装根治
