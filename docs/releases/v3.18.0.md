# v3.18.0 发布记录

> 日期：2026-09-11
> 上一版本：v3.17.0（2026-09-10）
> 提交数：65 commits（2026-09-10 ~ 2026-09-11）
> 性质：**功能大版**——Provider 重试与限速全链路可配（issue #75 落地）+ 审查 worker 隔离机制 + 桌面端滚动跳动终局修复与一批体验改进（信任引导 / MCP / Composer 排队）。

## 新增

- **Provider 重试与限速全面可配（issue #75）**：重试退避曲线（`baseDelayMs` / `maxDelayMs` / `jitterRatio`）、按错误类别覆盖（`overrides`）、总时长预算（`maxTotalDurationMs`）与客户端令牌桶限速（`requestsPerSecond` / `burst`，默认关闭）均可在 config.json 配置。关键修正：配置退避曲线后，429 等可重试类别首次获得**真正的指数增长**（此前延迟基准固定、只加抖动不加指数增长）；显式 `maxRetries` 不再被分类器默认值夹取（配置 8 就按 8 执行）。`maxRetries` 上限 0–10 → 0–20（TUI 旋钮同步），文档新增「重试与速率限制」章节（含每类别默认值表）。
- **桌面端「重试次数」「每秒请求上限」配置**：Provider 面板调优区新增两个数字输入——留空 = 引擎默认（推荐），清空即恢复；随卡片展开渐进披露，不打扰新用户（issue #75 桌面端）。服务端 tunables 通道与回显同步扩展，旧 sidecar 兼容（缺字段视为未设置）。
- **项目信任引导（桌面端）**：未授信项目打开时给出可见提示并支持一键授信；「不再提示」写入服务端 `project-trust.json`（与 TUI 对称）；信任状态收敛为单一真源，项目级引导与 MCP 面板闭环。
- **审查 worker 隔离机制落地**：审查/补丁类 worker 改在独立 worktree 运行——隔离判定按「写入是否与主控重叠」（而非 profile 名），team 正交分片不受影响、保持共享模式（不回退为整树 checkout）。补丁工产物回流闭环：逐轮文件清单与摘要经 ReviewOutcome 披露给主控（verified / rejected 两条出口均携带）并明示「未落入你的工作树」，产物可经 `diffArtifactId` 取回。
- **MCP 配置增强（issue #72）**：应用代理注入 stdio 子进程 + 子进程退出错误归因；桌面端 MCP 手动表单支持 `env` 输入；新增《MCP 服务器配置指南》（env / timeoutMs / 代理 / -32000 排查）。
- **Composer 排队入口恢复（桌面端）**：运行中提交恢复排队（busy 提交进 queue lane）；run 收尾自动 flush——排队消息不再滞留为死信；slash 命令与纯附件在排队入口拦截并提示（queue 通道仅纯文本，命令不会被当字面内容发给模型）。
- **review defer 可见性**：defer 的审查延迟对用户可见（去掉内部参数名），累积状态可通过 status 查询；`/review` 现在并入并消费待终审累积——「敲 /review 立即审查」承诺兑现，收尾终审不再对同批文件二审。

## 修复（重点条目）

**桌面端滚动稳定性**

- **展开态高速滚动跳动终局修复**：滚动期挂账收缩的行在 flush 时推后结算（用户仍在滚动窗口边缘时不硬收缩），配合收缩账本记录。三轮回归：maxSwing 40px（噪声级）、spontaneousUps=0、精确钉底——对照 3.16.1 基线 1646px 量级消除。
- 测量结算可观测性：measure-flush 打点（积压行数 / 跨帧数 / 流式态 / 耗时）。

**Windows 桌面端（issue #77 覆盖安装残留防护）**

- **node-runtime 结构漂移清理**：覆盖安装前整体删除旧 node-runtime，由新包全量重铺（NSIS PREINSTALL hook + 取证日志）；staged runtimes（rivet-runtime 全量副本）同批清理。
- **构建链 fail-closed**：fetch-node-runtime 全量重建（先删后拷）——消除目录合并语义在旧布局残留下的模块解析遮蔽；npm 复制失败 / 源缺失从警告升级为中止，半成品 runtime 不再原样送达用户。
- MSI 通道核验天然免疫同类残留（tauri-bundler MajorUpgrade 先整体卸载后安装），结论就地归档防重复调查。

**Worker 与审查链路**

- **OOP worker 进程组修复**：Unix 上 detached 自成进程组——`killProcessTree` 组杀真正生效并注册进退出清理。
- **移植公开仓 PR #78**：abort 监听摘除 + settle 遗留后代组杀与 exit 兜底缺口修复。
- 审查/补丁 worker 建树失败不再静默就地写：isolated 策略 fail-closed（abstain + `policy_short_circuit` 上报），不再改写用户主工作树。

**安全**

- **信任门剥离清单补 `network` / `fetch`**：封堵未授信仓库经 MCP 代理改向 MCP 子进程出站、经 `fetch.jinaBaseUrl` 改向 web_fetch 正文抽取（目标 URL 外发 + 回流注入双通道）。

**TUI**

- **空闲 + 有输入时 Ctrl+C 恢复清空草稿**：不再误弹退出确认窗。
- **小屏推理区两档收缩**：回复可见行从 1 行恢复（用户反馈）。
- `/help` 补列 `/trust`（授信命令此前未在帮助中出现）。

**桌面端**

- **供应商「测试连接」反馈可见化**：补样式 + 可行动化 + 场景引导。

**其他**

- **嵌套配置递归合并**：修复 provider `retry` 嵌套子键（如 `rateLimit.burst`、`overrides`）在桌面端改配置时被静默吃掉（对抗审查 F1）。

## 已知问题

- **桌面端 Insights「登录 DeepSeek 平台」会导致程序卡死**：该登录功能当前暂不可用——请暂勿使用，等待后续修复。

## 升级说明

- 从 **3.17.x** 自动更新即可，无配置迁移。
- **重试/限速配置完全可选**：不配置 = 既有行为（按错误类别默认重试 + 不限速）；桌面端相应控件留空即默认。此前手工写在 config.json 的 `retry` 块照常生效，与 UI 共存（子键级合并，互不吃掉）。
- **审查/补丁 worker 改在独立 worktree 运行**：产物经披露行告知，不再就地改动你的工作树；team 正交分片行为不变。
- **Windows 用户**：覆盖安装会全量重铺 node-runtime（issue #77 修复），旧安装残留不再遮蔽新模块解析。
