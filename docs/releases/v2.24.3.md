# v2.24.3 迭代记录

> 日期：2026-07-28
> 上一版本：v2.24.2（2026-07-28）

## 主题：domain picker 切换退出后输入框叠影修复 + macOS 双架构发版

v2.24.3 是 v2.24.2 的 hotfix——修复一个 TUI 渲染回归，同时正式发布 macOS 双架构桌面版。

---

### 1. domain picker 切换退出后输入框两层框体叠影（hotfix）

**症状**：`/domain` 切换星域后退出选择面板，主屏输入框框体画了两层（`╭─ 天枢` 顶框叠加）。

**根因**：v2.24.2 的 overlay 退出流程中，`onExitAltScreen` 回放排队 commit 时 `commitAbove` 内部的 `renderLive` 画了第一帧，随后 `deactivateOverlay` 的 `reset + renderLive` 走 append 叠在第一帧下方。

**修复**：`deactivateOverlay` 在 `overlay.deactivate()` 前置 `suppressCommitRender`，让回放的 commit 只写入 scrollback、不触发 renderLive，最后由 `deactivateOverlay` 统一渲染唯一帧。

### 2. macOS 双架构桌面版正式发布

v2.24.2 仅发布了 Windows + CLI，本版补齐 macOS：
- **Apple Silicon (arm64)**：`Tianshu_2.24.3_aarch64.dmg`
- **Intel (x64)**：`Tianshu_2.24.3_x64.dmg`

每个包只含目标架构的 Node / better-sqlite3 / esbuild / @ast-grep 原生二进制（不再混入异架构，修复了此前 Intel 包在 Intel 机上 sidecar 崩溃的问题）。

### 3. 打包脚本修复

`build-macos-release.sh` 的版本号断言此前硬编码 2.24.0，改为从 `package.json` 动态读取，避免每次发版手动改。
