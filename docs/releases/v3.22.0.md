# v3.22.0 发布记录

> 日期：2026-09-18
> 上一版本：v3.21.1（2026-09-16）。v3.21.2 未对外发布，其全部内容并入本版。
> 性质：**功能版 + 修复版**——MCP 健康检查与熔断上线、Windows 平台修复批次（含 issue #144 进程树治理收口）、模型引用别名解析、桌面端多处体验修复；含一项 API key 落盘加密安全增强。

## 重点新能力

**MCP server 健康检查与熔断**

周期性 `tools/list` 探测 + healthy / degraded / failed / retrying 状态机 + 指数退避。故障或失联的 MCP server 不再拖慢会话，恢复后自动回到健康态。（收编 Tianshu-harness PR #201 · jian-in，移植时修正心跳调用形态与定时器 unref 两处问题）

## 安全与凭据

**Provider API key 落盘加密**

`secrets.json` 此前是明文 JSON，只靠文件权限保护——而 `0o600` 在 Windows/NTFS 上不生效（权限由 ACL 决定），该目录又常落在云同步/备份路径上。现在与账号 token 同一套策略：**AES-256-GCM 信封**，数据密钥托管在系统密钥库（macOS 钥匙串 / Windows DPAPI，不可用时降级本机密钥文件并明确告警）。旧明文文件仍可读取，下次写入自动升级。

## Windows 平台批次

- **进程树不再留孤儿（issue #144）**：超时后 `taskkill /T` 枚举式清理追不上仍在写盘的子孙进程。改为让 shell 出生就在作业里——新增原生作业持有者（`native/job-launch.c` → `job-launch.exe`），`CreateJobObject` + `KILL_ON_JOB_CLOSE` 后自身入作业再拉起真 shell；终止时只杀 helper 一个进程，作业句柄关闭即带走整棵树。实机对照（贡献者 Windows 11 25H2 留档）：改前打点 6 → 10 仍在写（泄漏），改后 4 → 4 已停、残留 0。helper 解析不到时原样 spawn（fail-open）。
- **脚本按扩展名选解释器**：`.sh` 不再被 cmd「打开」并弹出「选取应用」对话框（来源 PR #199）。
- **打开无关联扩展名的文件退化为定位**，不再留下永久「选取应用」对话框（issue #193，来源 PR #195）。
- **计划文档的返回路径归一为 POSIX**，不再泄漏 Windows 原生分隔符（来源 PR #197）。
- **import-graph 两处路径缺陷修复**：绝对路径判据 isAbsolute 化、index 候选按原生分隔符拼接（来源 PR #200）。
- **meridian 快路径的写工具路径归一**：此前 Windows 上改动影响面提示（impact hint）静默全灭（来源 PR #194）。
- **Windows 测试套件四类平台假设收口**（issue #188 / #189）。

## 模型

- **模型引用解析接入别名表**：短名 / 旧名引用不再静默回退到列表第一个模型（收编 PR #182）。
- **模型池口径统一走契约层**：只在 key 池里的模型不再失配。

## 桌面端

- **存储位置应用必现失败修复（issue #162）**：`/Volumes/` 前缀此前被一律判成网络卷；现在改判真正的网络卷，失败原因直接透出、不再被吞。
- **Mermaid 图黑块修复**：暗色主题下节点填充与文本色不配对，改为 accent 填充配对 accent-fg 文本，明暗判定走 `data-scheme`。
- **Windows 附件对话框不弹出修复**：开框前显式取回窗口焦点，真实错误上界面。
- **输入框模型列表支持按 provider 分组折叠**，会话内与欢迎页统一。
- **PlusMenu 布局重组**：菜单高度约减 40%；审查等子面板悬停闪烁修复（拆除双浮层嵌套）。
- **health 横幅误报修复**：单次超时不再报「sidecar 未启动」。
- **右栏首开链路布局跳动修复**；输入框上方活动条遮挡消息修复（overlay 实测高度补偿）。

## CLI

- **版本号不再被外层项目冒充**：`rivet --version` 在 runtime bundle 被解压进「自带 `package.json` 的目录树」时，向上寻找包根会继续上溯命中外层无关项目。现在同时校验包名，解析不到就不显示（而不是显示错的）；顺带修复包根被 `dist/package.json` 劫持导致欢迎页版本号消失。
