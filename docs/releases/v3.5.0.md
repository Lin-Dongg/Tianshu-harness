## 1. 计划文档全屏预览（`1efbc8da6` + `4a7890154`）

plan mode 创建计划文档后，TUI 此前没有任何全文查看途径——审批卡只有 6 行 × 76 列截断摘要，plan-picker Enter 直接批准不显示正文，用户要等到批准执行才知道计划写了什么。本期补齐：

- **审批卡按 `v`** → 复用全屏 pager 看计划全文（固定每页 `height-4` 行，PgUp/PgDn/j/k 翻页、`/` 搜索、标题页码），`q`/`Esc` 返回审批卡，Goal 倒计时状态不丢；驳回反馈输入子模式中 `v` 仍是普通字符。
- **plan-picker 按 `v`** → 预览选中计划再决定是否批准。
- **`/plan-view [ref]`** → 随时查看任何计划；无参时优先唯一的待审批计划，否则显示 plan mode 撰写中的活动草稿（每帧现读文件，agent 边写边翻页可见新内容）。已入命令面板。
- 实现要点：`readPlanSync` + `stripPlanChrome`（剥 frontmatter 与 Status/Model 留痕行）进 plan-store；预览指针复用 pager overlay，退出按 returnTo 回原面板；预览态 footer 提示覆盖（无 verbose/message 可切）、读失败显式兜底不静默跌回 scrollback。

## 3. TUI 交互三连修（公开仓 PR #46 / #49 / #50，作者 yq04）

- **命令面板视窗跟随选中项（#46）**：命令多于屏时按 ↓ 高亮滚出可视区而列表不动（`slice(0, maxItems)` 恒取首页）——改为 Codex `ensure_selected_visible` 式视口跟随（↑ 在视口内只移高亮不弹回首页、循环到首尾正确落位、footer 显示 `↑N/↓N` 溢出计数）；首屏 `ctrl+p` 独立成条并与斜杠命令同走主题强调色。
- **输入框钉住（#49）**：live 区高水位从「只记动态段」改为「记动态 + chrome 总高度」——slash 提示、权限行、todo 面板等 chrome 关闭后垫行补差，输入框不再「有时贴底、有时上跳」。
- **排队消息本轮结束自动发出（#50）**：`⏳ 已排队` 内容在 run 自然结束后自动作为下一轮发出（多条 FIFO 逐条发），不再拉回输入框等用户再按 Enter；ESC 仍回填交还编辑、输入框有草稿不抢发；⏳ 条从动态区挪到输入框正上方不随工具卡上漂；覆盖 `agent.run()` finally 与 isFinal flush 的竞态。
