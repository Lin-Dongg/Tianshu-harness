## 0. v3.15.0 用户升级指引

v3.15.0 是回退到 v3.9.0 行为基线的过渡版。升级 3.16.0 后将获得 3.9 基线之后的全部能力与修复（滚动新架构、权限五档体系、issue #63 全链、无进展哨兵等）。已知待办：手机遥控功能仍在修复队列中，本版不含。

## 1. 滚动稳定性大修（桌面端，本版最重战役）

v3.10–3.14 期间滚动换代引入的弹跳/拉扯/滚不动问题，本次经设计文档 + 抖动度量探针 + 真机（IAB dev 环境）取证逐层根治：

- **流式会话开始即上下拉扯根修**（`692ea7755`）：模型输出引起的行高收缩被误判为「用户上翻」导致的两拍拉扯，经真实 virtual-core 实例三连钉死肇事机制后修复
- **滚轮滚不动回归修复**（`6379f8e7e`）：流式期模型收缩打点会吞掉用户上翻意图（手势闭嘴门 + repin 只认真钳位指纹）
- **收敛环补全**（`492c6785b`/`5581bb55d`/`386da4ade`/`3fe263ced`）：intent 成为 Reading 状态唯一合法之门；内容收缩永不脱扣（组折叠是系统行为）；几何驱动追底 chaseGap 补全（几何变化不产生 scroll 事件的盲区）；实测 intent 翻转/误扣归零
- **下滚被首测修正批量弹回根修**（`0cf8b882a`）：快速下滚时 overscan 批量挂载的首测修正每批平移视口（每滚一下弹一下），用户滚动期接管补偿谓词后实测 bounceCount=0
- **展开态滚动条拉不到底回弹根修**（`b435d500d`）：行内展开态估值盲区 / wasAtEnd 钳位恒真 / 5s reconcile 拽回陈旧目标三层根因逐层修复；展开态跨卸载存续提升到 store（`70f96f984`）
- 原生滚动锚定（overflow-anchor）A/B 开关保留（`rivetAnchorNative=1` 可试），默认仍走 JS 补偿链
- 已知残余（如实）：流式输出期间用**滚动条拖拽**上行可能暂时拽不脱离跟底（滚轮/键盘不受影响）；滚动验收判据尚未在真机桌面端做量化验收（取证均为 IAB dev 环境）

## 2. 写工具挂起根治 + 无进展哨兵（agent 稳定性）

v3.15 说明点名的「写工具挂起」问题族，本版多层收口：

- **写工具挂起三件套**（`90c8c98ef`）：esbuild 语法检查 worker 化、CPU 任务出主线程、meridian 绝对路径——写工具收尾不再阻塞主循环
- **写后挂起事故族加固**（`b76861adc`/`0e792e26e`）：超时信息带目标、write_file 迟到写防护、display-only 软上界、工具总闸/续跑降级/磁盘对账
- **无进展哨兵 stall-observer**（`38b246ba6`）：回合死锁主动观测（60s tick / 150s 阈值），指认哪个会话、最后活动是什么、静默多久——不再依赖超时触发或现场抓栈；后续三笔收口修复残留重报与交付后误报（`956564a83`/`b3329e590`/`029421c36`）
- **磁盘对账判据单源**（`c77427d21`）：正常切换会话不再付 270-447ms 全树扫描；TTL 快照失败不进缓存
- **meridian 阻塞四项修复**（`641c5c9d7` 等）：同步索引不再阻塞事件循环（read 廉价探针入队 / write 去抖 / 批量符号查询 / 批间让出）+ 队列 follow-up 加固；CLI 侧消除写工具收尾每会话 ~750ms 全量扫仓（`9a9bbf49b`）

## 3. 权限五档体系重构（重要行为变更，升级须知）

- **完全权限档（yolo）语义变更**（`6ff919118`）：完全权限 = 免审批 + 默认**无沙箱全盘读写**；写沙箱仅在显式 `RIVET_SANDBOX=1` 时启用。CLI `rivet config set-approval --unsandboxed` 一键开启
- **免审批档零打扰**（`4c988c218`/`2828ccc06`）：plan 提交即批准、出界路径首触即授、bash 沙箱拒绝首触授权自动重跑——skip 档的「零打扰」承诺覆盖到沙箱层
- **免审批档提示注入**（`def690436`）：模型在免审批档下不再「先申请再动手」（动态 appendix 提示不冻结、不碎前缀缓存）
- **跨盘写审批断链修复**（`07115dfac`）：档位回读/实时广播 + 审批全局可见性——/cd 切盘后审批不再失联
- **桌面端档位 UI 一致化**（`c8af11b93`/`ffa7274a2`/`d4fb422ba`）：全局默认档层 + 会话跟随/钉档 + 档位显示如实解析（「界面权限=实际权限」）

## 4. 前缀缓存稳定性（v3.15 回退的主因之一）
