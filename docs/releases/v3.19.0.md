# v3.19.0 发布记录

> 日期：2026-09-12
> 上一版本：v3.18.1（2026-09-11）
> 性质：**功能版**——Mobile Remote 手机遥控全链路上线、视觉识图开箱化、技能生态三连（标准目录 / 斜杠唤起 / 桌面插件闭环）、附件全链路（含 PDF 开箱可读）、Windows 桌面端专项、两项实测级性能根修。

## 重点新能力

**Mobile Remote 手机遥控（全链路上线）**

- **设置页开启远程访问**：Settings → 网络 → 远程访问区块展示监听模式徽章（仅本机 / 局域网）、访问地址、令牌遮显与复制、二维码——手机扫码直达 `http://<局域网地址>:<port>/mobile/`（未显示令牌不绘制二维码；回环模式不画不可达死码，给启用引导）。
- **手机 Web 端**：会话列表（待审批徽标置顶）、只读时间线（SSE 实时流 + 断线轮询回填 + 历史分页）、审批三卡（工具授权 / 计划批准 / 智能体提问）、中止运行。局域网下 Bearer 令牌是唯一凭证，请勿暴露公网（Tailscale/SSH 隧道亦可）。
- **交互与健壮性一轮**：审批操作本地反馈（离线不再卡「…」）、审批并发冲突可读提示、时间线贴底跟随、锁屏/切后台回来自动促连（重试预算耗尽的流由 visibility/pageshow/online 与 sidecar-restarted 事件唤醒）、断线回填同 seq 去重（流式文本不再翻倍）、触摸目标/输入缩放/空态文案适配。
- **安全收口**：Host allowlist 三分支（回环恒放行 / 精确匹配 / LAN Bearer 兜底）、`/mobile` 路径穿越与符号链接逃逸防护（realpath 逐请求校验）、无斜杠 302 规范化、`::` 不再误判回环（IPv6 通配绑定下 LAN 可达、模式显示不再误导）。
- **Termux 适配（Android 跑 TUI）**：安装守卫与指引、Ctrl+S/Ctrl+Q 输出冻结接管、矮屏降级。

**视觉识图开箱化**

- **同 provider 视觉档默认自动挂载**：只要主服务商下有可用视觉档（如 deepseek-flash），配了 key 就能直接读图——无需任何设置，不再要求显式配置识图桥。旧 `deepseek-v4-flash-vision-exp` 档退役并一次性迁移到 `deepseek-flash`。
- **模型终于能看到图（根修）**：修复用户附图的图片 parts 被 volatile 合并丢弃的问题——多模态 parts 保真进上下文；`image_stripped` 剥图提示接到状态行不再静默丢弃。
- **图片上限对齐 10MB**：sidecar 单图上限 1.5MB→10MB（与 TUI/压缩出口/read_file 同口径），DeepSeek 原生多模态大图不再被 400。
- `/model` 列表标注视觉能力，同名档不再无法分辨；识图桥 source 契约统一（主模型原生支持不再误显示「桥已生效」）；欢迎页带图发送三处体验缺口收口（行内常驻错误 / 看不到图提醒 / 创建窗口期不清场）。

**技能生态三连**

- **`.agents/skills` 双槽位自动扫描**（issue #100）：用户级 `~/.agents/skills` 与项目级 `.agents/skills` 自动装载——与 Kimi Code 等跨 agent 标准目录零拷贝互通，五层优先级链（生态技能可被 rivet 原生覆盖）。技能不进冻结锚，前缀缓存稳态命中率不受影响（discovery 块硬 capped）。
- **技能即斜杠**（issue #100 建议②）：`/name` 裸名直调（Claude Code 形态，TUI / 桌面 / headless 同链路），桌面 Composer 的 `/` 菜单新增技能区——装技能 → 菜单可见 → 选中即插入 `/name` 参数透传。
- **桌面端插件闭环**：sidecar 会话装配插件（启动暖场缓存 + 每会话同步合入快照）——桌面设置页安装 office-pdf / office-excel / office-docx / office-ppt 后，下一个新会话的 agent 即拥有 `pdf_create`/`pdf_read` 等工具（此前插件只对 TUI 生效，桌面装了无感知）；安装/启停/卸载即时失效重建。配套防线：sidecar 插件冲突检测基座补内置工具全集，同名插件工具不再静默覆盖内置工具。

**附件全链路（欢迎页也能传文件了）**

- **欢迎页附件上传**：PlusMenu 图片/附件按钮接通原生文件对话框（此前是空函数），支持按钮/拖拽（含 OS 级拖入）/粘贴三通道——图片压缩挂载、文本内联、文档（pdf/office）随新建会话发送。
- **POST /sessions 支持 documents**：文档附件服务端抽取文本前置进首轮 prompt（与 /prompt 同一管线）——「先建会话再发附件」的别扭流程成为历史；NewSessionDialog 同步支持。
- **PDF 开箱可读**：doc-extract 新增 pdfjs 纯 JS 兜底引擎（poppler 在则优先 `-layout` 排版，不在也能出文本）——此前没装 poppler 的机器 PDF 只能拿到失败标注。另修复 exceljs 在 Node ESM 下 xlsx 抽取静默全灭的潜伏 bug。
- **附件链健壮性**：前端 base64 分块编码修复 150KB 以上附件必崩（栈溢出）、服务端文档扩展名白名单与体积前置校验——大附件失败路径全部可见可控，不再静默。

**集成终端可选 shell（Windows 为主）**

- 终端新建页可选手动指定 shell：PowerShell / pwsh（PowerShell 7）/ cmd / Git Bash / 自定义可执行路径，设置页持久化，新 tab 生效；自定义路径失败原因显式写进终端（不再静默落到别的 shell）。
- 顺手根修 `resolve_shell_path`：旧候选表与请求名无关、取首个存在者（选 pwsh 可能给你 PowerShell 5）；现按名解析到真实安装位（`Program Files\PowerShell\7` / Store alias / PATH 遍历兜底），找不到明确报错。

**Windows 桌面端专项**

- **控制台闪窗三层修复**（issue #103）：taskkill/where 等 spawn 调用点统一 `windowsHide`、WebView2 探测 reg query 补 `CREATE_NO_WINDOW`、detached 语义与架构守卫口径升级——启动与日常操作不再弹黑框。
- **sidecar 内存分档全平台并表**：8/16/32/64GB → 4/6/8/12GB（原 Windows/Linux 保守表 3/4/6/8GB 上调；heap 按需增长，低配护栏在 Node 侧梯度降级）；**Windows 物理内存读取**（经 wmi 查 Win32_ComputerSystem）——从「一刀切回退」变为真实分档，32GB+ 机器自动拿到 8/12GB。
- **GPU 探测过滤虚拟/软件适配器**（issue #106）：Windows 面板不再把 gameviewer 等虚拟设备当成真 GPU。

## 性能（两项实测级根修）

- **Meridian 影响面分析 670s→0.4s**：`[slow-sync-stage] meridian-impact took 4s` 警告的根因定案——三处前缀查询的 SQL 拼接 GLOB 让 SQLite 放弃索引退化为 22 万边全表扫描，analyzeImpact 三跳 BFS 在枢纽文件上累计成灾难。前缀模式改 JS 侧整体绑定后走索引（单查询 ~1s→0.9–4.4ms，结果集逐字节一致），写工具后处理回到毫秒级。
- **写工具「卡死→冻结」链路根修**：macOS 桌面端复发的 write_file 卡死（落盘成功但结果回传断链 → orphan tool_use → reliability mode 冻结写工具，完全权限也无效）——两个事件循环 stall 源全部收口：meridian 全扫（上条）之外，meridian 冷库（新项目/索引为空）时写工具回落的整仓同步扫描改后台分片构建（批间让出事件循环），构建未就绪的写入跳过提示即返回，写结果零等待；共享构建状态挂 AgentLoop 会话级配置对象（经两轮审查修正——初版挂逐调用新建的 deps 包曾致 hint 全灭 + 每写重复扫描，executeBatch 真实接线回归钉死）。abort 落窗丢结果的链路就此失去生产源。
- **桌面滚动稳定性逐类量化修复**：次级抖动按机制归因、分别去除——虚拟列表 spacer 与行集同帧落布局（reduced-motion 全局过渡改 0s，滚不到底/拉扯根因）；运行态呼吸点出流（statusSlot 进动作行，ThinkingStatusChip 不再挂拆卸行）；JobAwaitStrip/ctx-nudge 移入出流悬浮层（委派密集的 run 中途挂卸不再让胶囊高度变化）——胶囊高度全程恒定，钉底视口不再挪行。
- **ad-hoc tsc 跨进程串行 + 结果回放**：worker/会话经 bash 直跑 `tsc --noEmit` 此前绕开门禁锁——galaxy 波实测 17–19 个并发 tsc 互相 CPU 饥饿、无一取得 exit code。现在 ad-hoc 全量类型检查与交付门禁共用同一把跨进程锁（git 顶层归一、后台 job 持锁），同指纹同命令直接回放零耗时，并发压到 1 个；另加磁盘低水位可见警告与缓存写跳过。

## 安全与健壮性

- **跨会话写保护闭环**：R2 写前独占守卫扩到全部写工具（hash_edit/ast_edit/apply_patch/plan_close，收编 PR #111）；sidecar 启动收割崩溃会话的幽灵独占锁（收编 PR #110）——硬杀后的死锁不再永久阻断写入。
- **路径授权表按工作区分域**（收编 PR #84）：sidecar 多会话下 A 项目的目录批准不再泄漏给 B。
- **撤销与检查点**：undo/rewind 不再把「备份读取失败」当成「文件当时不存在」而反向删除既有文件（收编 PR #88）；prune 不再删除读不了的 checkpoint（收编 PR #86）；apply_patch 失败分支回滚半套用状态（收编 PR #112）。
- **杂项**：LSP 服务器崩死有界重启恢复（收编 PR #87）；剪贴板 TIFF→PNG 转换守卫看注入 platform（收编 PR #90）；CVM 注入预算裁剪先于送达记账（收编 PR #82）；会话转录写入丢批与 flush 竞态修复（收编 PR #81）；运行时 hook 超时后迟到收尾兜底（收编 PR #83）；定时任务记住创建时工作区（收编 PR #85）；ast_edit 预览不再被当成落盘内容喂安全扫描；sidecar ESM 崩溃双保险 + DMG 安装 EULA 中文乱码修复。
- **TUI 输出冻结死锁根修**：Ctrl+S 冻结期若有内容入队（如 slash 命令输出），渲染泵守卫不对称导致微任务自旋饿死事件循环——Ctrl+Q/Ctrl+C 全部失效只能杀进程。修复后冻结期宏任务正常调度、解冻后队列续排（输出冻结为 Termux 适配引入的功能，本修复覆盖全部终端场景）。
- **DeepSeek 登录失败不再静默吞错**：OAuth 登录失败的真实原因上屏展示（此前只见失败不见原因）；Tauri 应用内不再改走系统浏览器。
- **chromium 安装钉在内嵌 playwright-core 版本**（收编 PR #109，issue #102）——装完不再误报未安装的死循环。

## 模型与配置

- **DeepSeek `deepseek-v4-pro` 退役**：strong 档由 `deepseek-flash`（V4.1）承接（已按官方多 agent 训练与 effort 通道调研校准，见 docs/analysis）。
- **模型名失配不再静默换档**：配置/headless 指定的模型解析不到时明确报错（此前静默回落默认模型）；opencode-go 的 deepseek 条目 maxTokens 回到官方标称 384K。
- **供应商管理三连修**：CJK 名供应商删除全灭修复、预设删除复活修复、key 修改热生效（下一个新会话生效，无需重启）。
- **「测试模型调用」不再谎报**：判分抽公共实现——URL+Key 连通但从未实测 completion 时如实提示「连接有效（未实测对话）」，不再把连通性当模型可用；DeepSeek 登录失败真实原因上屏。

## 已知问题

- **MiniMax-M3 视觉上游故障**（延续）：MiniMax 服务端对 M3 图片请求返回 500（纯文本正常）——M3 作识图桥暂不可用，建议 glm-4v-flash / glm-5.3-flash / deepseek-flash。
- **手机遥控为局域网设计**：无 HTTPS——令牌是 LAN 唯一凭证，公网访问请走 Tailscale/SSH 隧道，不要直接端口映射。
- 已打开的桌面会话不热更新新装插件（下一个新会话生效，与技能装载语义一致）。

## 升级说明

- 从 **3.16.x / 3.17.x / 3.18.x** 自动更新即可，无配置迁移；`deepseek-v4-flash-vision-exp` 与 `deepseek-v4-pro` 引用自动迁移到承接档。
- 手机遥控默认关闭（仅本机监听）：需手机访问时在 设置 → 网络 → 远程访问 按引导以 `RIVET_SERVE_HOST=0.0.0.0` 重启应用或桌面端，扫码即用。
- Windows 用户升级后 sidecar 堆上限自动按新分档生效（可用 `RIVET_SIDECAR_HEAP_MB` 显式覆盖）。
