# v2.19.8 迭代记录

> 日期：2026-07-20

## 主题：TUI 交互对标优化 · 审查门分层 · 交付门去阻塞 · 计划模式闭环

### 1. TUI 交互优化（竞品对标 P0/P1）

- **Todo badge-first**(c1e9c425)：状态栏分态计数徽章(compact `◇2/5` / full `◐1 ☐3 ☒2`),done 增加/total 变化反色高亮 ~1s(reducedMotion 不闪);`ctrl+x t` 展开面板,completed 逐条回看(原仅 6 行硬上限),主区与侧栏同键。
- **Overlay 活性**(c1e9c425):/tasks、cockpit 激活期间随数据/tick 实时重绘(≥400ms 节流)——修复打开即快照、worker 推进不可见。
- **子代理行升级**(c1e9c425):汇总头加耗时,行尾右对齐状态词列(执行中/完成/失败/受阻/升级),在跑时附 /tasks 管理提示行。
- **Tab 键位统一**(a68af369):cockpit 8 面板支持 ←/→/Tab/Shift+Tab 循环(原仅 /cockpit <面板> 命令),/tasks filter 补齐反向;三处共享同一语义。
- **折叠组时态化**(a68af369):live 进行体(Searching/Reading)沉淀后过去时(Searched/Read);Ctrl+O 可直接展开 live 活跃折叠组。
- **小窗口泄露修复**(95eb1970):LiveEngine 行预算改 display-row 感知——窄窗口折行帧不再越底滚屏,正文不再叠印到输入框下。

### 2. 审查门分层与预算修复

- **auto 审查 L1/L2 分层**(426ebd70):classifyAutoReviewTier 确定性分层——核心路径/≥3 文件/crossModule/forceLevel/依赖配置升 L2(spawn wiring inspector);小改动压 L1 零 worker 成本。
- **预算放大 + 早收敛**(426ebd70):wiring inspector 6 轮/150s → 12 轮/240s,外层 cap 180s → 300s;早收敛 prompt(前 1/3 轮只看 diff,最后 2 轮强制输出 verdict)。
- **场景化重试**(426ebd70):classifyInfraFailure 新增 budget kind(max-turns 耗尽);budget/timeout 确定性失败不再重试(根治同预算重试必死的空耗);inconclusive 标签三分:预算耗尽/超时/infra failure。
- **最终轮警告**(4eca8ed1):最后一个可用轮注入「最终轮」指令(禁新工具链、立即产出最终答复/WorkerResult JSON),并仅该轮重置 SR 计数保证送达——结构性缓解 max-turns 耗尽无终轮。

### 3. 交付门去阻塞(deliver_task 瘦身)

- **移除同步阻塞**(769c58ea):typecheck backstop(3 个 120s 子进程 await)与显式 review_level 同步 await(180s worker)移出 commit 门——根因是超时导致 agent 绕行裸 git、scoped commit 失效卷入跨会话文件。timeout 120s/180s+ → 30s/60s。
- **裸 git 交付禁令**(769c58ea):<shared-worktree> 明令禁止裸 git commit/git add -A 交付。
- **补丁 2 闭环**(f9c285cf):自跑 typecheck 失败时传 review_level='L3' 的 prompt 指引,保住 forceLevel 升级信号。

### 4. Plan 模式内核闭环

- **闭环自动退出**(4f0806ab):plan action=close 在交付门 GREEN(EXECUTED)时自动退出 plan mode——桌面端「闭环即解锁」;未执行时退出仍归用户,worker 上下文不退出。
- **模型引导语去 CLI 化**(4f0806ab):批准=会话内审批卡片/面板按钮,不再要求用户输入 /plan-approve。

### 5. 可观测性

- **/tasks 命令消歧**(4eca8ed1):补入命令面板(registry 早有但不可见);/task 废弃桩文案指向 /tasks。
