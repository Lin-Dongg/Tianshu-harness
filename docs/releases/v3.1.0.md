## 1. 目标锚（goalAnchor）系统 —— 长程任务的方向固化（三波完成）

目标锚把会话目标从「易失的隐式状态」固化为显式、跨端、可回显的载体，长任务不再随上下文滚动漂移：

- **提取与注册**（Wave 1/3）：spark 目标锚提取器 `goal.ts` + pro-registry 新增 `goalExtractor` 注册点
- **固化载体**（Wave 2/3）：`SessionMetadata` 增 `goalAnchor` 字段；volatile `<current-goal>` 段常驻回显 + engine `setGoalAnchor`，缓存安全模拟测试 7b
- **接线闭环**（Wave 3/3）：`SessionContext.setGoalTracking` 更新钩子 + 真实管道 e2e 测试；bootstrap + server 双路径（TUI + sidecar）固化/补课/增量更新
- **审查修复链**：serve-agent 目标锚注入移出历史消息块（首启也注入）、baseline 复用历史提取结果（不二次调用 extractor）、`setGoalTracking` 加 `initialBaseline`（frozen 不被初始提取覆盖）

## 3. desktop —— Win10 适配、滚动闭环、启动性能

- **Win10 适配**：关窗口阴影 + WebView2 版本检测 + overlay 滚动条（会话区拉扯/触底反弹）+ computer-use 截图 PrintWindow 化（遮挡/后台/平板模式截图不瞎）+ snapshot 撤屏自愈（离屏坐标 -32000 触发窗口恢复再重 walk）
- **设置页「完全权限」档**：跳过审批 + 关写沙箱
- **ripgrep 自带分发**：grep 工具不再依赖系统 PATH 的 rg
- **滚动裁决闭环**：抽取 `useScrollController` + E2E 覆盖 16 事故场景；滚轮回底中放行 repin（wheelDirDown 豁免冷却窗）
- **启动与首轮响应四件套**：compile cache / 看门狗降噪 / loop-lag 归因 / 首屏骨架
- **资源策略调整**：sidecar 堆上限平台分表（macOS 自适应整体上移，8GB 不再卡 2GB）；取消低内存自动 lean——8GB 默认全功能，改一次性引导提示由用户自选
- **语音识别引擎优先级回归**：Web Speech 系统识别恢复主链路，whisper 仅兜底（2.29.0 起双平台被 tiny/base 小模型顶掉）
- **其他**：性能设置保存根修（7 个自定义命令补登 Tauri ACL 白名单 + 防回归契约测试）、会话流小窗闪烁与底部遮挡根修、子代理面板选中态键语义对齐、模型供应商视觉标记可发现性、慢思考三态控件（Default/On/Off）

## 7. 推理展示调研与缓存实证（docs/analysis 归档）

- **外部实现调研**：Codex 桌面版/CLI 与 Cursor 的推理展示策略（模型侧摘要 vs 客户端启发式）
