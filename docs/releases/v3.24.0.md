# v3.24.0 发布记录

> 日期：2026-09-21
> 上一版本：v3.23.1（2026-09-19）。本版覆盖 `v3.23.1..HEAD` 共 **165 个提交**（含 31 笔公开仓贡献计入住）。
> 性质：**功能版**——手机端 `/mobile` 从可用走向成型；自动化任务获得原地更新与停止终态；排队消息支持附件；一批安全加固与 3.14alpha 回流落地。

## 手机端 `/mobile`

- **设计层 token 化 + 三屏重排**：`/mobile` 页面改为 token 驱动，列表 / 详情 / 输入三屏重排，compose 可直接下指令。
- **功能闭环**：手机端可发起任务、插话纠偏、查看产物、调整模型档位——不再只能看不能动。
- **推送通道 + 收件箱**：列表改由 `GET /events` 驱动，首页按「待办」优先分组，不再依赖轮询式快照。
- **注意力分层 + 进程可见性**：设计深化，状态覆盖补全——手机上能看出「在跑什么、卡在哪」。
- **交互手感**：返回不丢滚动位置；代码块可读可复制；软键盘不再遮挡输入框。
- **配色可用性收口（承接 2026-09-19 黑底黑字事故的同类）**：语义色（`--accent/--success/--warning/--error`）此前是**填充色**却被当**文字色**用——27 个内置主题里 9~15 个不达 WCAG AA，审批按钮写死白字最差 1.36:1。本版新增两组派生 token（`--{x}-fg` 填充之上前景、`--{x}-text` 文字角色的可读版本）与 `--accent-fg` 可读下限（只提升不降低），26 处「填充色当文字」改走新角色，13 个兜底整组双态。全 27 主题 × 4 色派生后 **0/108 不达标**。
- **发送链路修复**：`sendPrompt` 先前发 `{text}` 形态被服务端 400，问题回复链路全灭；手机 entry 的静态闭包不再含桌面客户端代码（惰性加载）。
- **自带 `/mobile` 页面**：新增指南与可运行示例页（收编 PR #211 / #214 · moyan3691）。

## 自动化任务（issue #236 / #237）

- **原地更新**：`PATCH /schedule/:id` 可改 prompt / trigger / 允许工具 / 审查策略 / 重试 / agentId——不再需要「删除重建」。不变式：id、创建时间、运行计数、生命周期状态不受补丁影响；可选项三态（缺席不动 / 显式 null 清除 / 值覆盖）。
- **停止终态**：新增 `status: active | paused | stopped`，`enabled` 降级为兼容镜像（随写同步），旧数据无损派生并在下次写入自愈。`stopped` 保留定义与历史（区别于物理删除），四条触发路径（tick / 事件 / 试跑 / oneshot 立即触发）统一收敛到单一谓词。
- **独立运行历史**：「全部运行」视图从全部运行记录反向归集，定义已删除的运行以孤儿组呈现——历史不再依赖「先选中定义」，删除定义不再等于丢审计能力。
- 设计文档：`docs/design/2026-09-21-automations-inplace-update-and-run-history.md`。

## 排队消息与附件（issue #238）

- **排队消息可带附件**：运行中排队的图片 / 文档随下一轮 run 一并发送，与 `/prompt` 同构（文档抽取正文前置在该条文本之前，图片按 FIFO 与文本同序）。
- **配额治理**：附件上限收敛为单一来源（`attachment-limits.ts`），入队与归并读同一组常量；单轮图片配额按「本轮新提交优先、排队 FIFO 补足」分配，超出按条目标注并显式告知（不静默截断）。
- **并发原子性**：配额判定的权威点移入无让出点的同步块——路由侧校验与提交之间隔着文档抽取的 await，并发的两条请求此前能双双通过再把队列顶过上限（已复现并修复）。
- **通道边界**：含附件的排队条目不能升级为「立即引导」（插话通道仅能传文本），显式 409 而非静默丢附件。
- **TUI 侧同族修复**：运行中带图提交此前图片被静默丢弃（气泡里图已显示、模型从未收到）——现在暂存到下一轮随 prompt 发出，并即时告知去向；两个提交出口（输入行与 slash/workflow）都接线。
- **桌面端**：宿主透传 + 排队卡片附件 chip + 含附件时禁用「立即引导」并给出下一步。

## 安全

- **GUI 输入注入进审批门（issue #235）**：agent 用 shell 跑 PowerShell`user32` P/Invoke 做系统级输入注入（抢占前台 + 合成键鼠）此前不落任何危险类别、静默放行。新增「可用性危害」签名类（`user32` P/Invoke、`SetForegroundWindow`/`SendInput`/`SendKeys`/`AppActivate`、`osascript keystroke`、`CGEventPost`、`pyautogui` 族、`xdotool`），manual 与 auto-safe 两档同时生效。
- **用户接管即让出**：`computer_use` 在合成键鼠 / 抢占前台前检测用户活动（macOS `CGEventSourceSecondsSinceLastEventType`、Windows `GetLastInputInfo`），检测到用户正在操作即让出；叠加自身注入余波窗口，避免每次注入都把下一次调用误判为用户活跃。
- **MCP 服务器连接级审批门**：连接建立即需授权，TUI 提供呈现与 approve/deny 入口（收编 PR #231 · EarthxxRhythm；issue #215）。
- **搜索 API key 迁 secrets-store**：`config.json` 不再落明文（收编 PR #227 · EarthxxRhythm；issue #220）。
- **web-fetch DNS 重绑定收口**：渲染路径用进程内 pin 代理钉住 DNS（收编 PR #228；issue #212）。
- **browser 工具逐请求防护**：重定向 / iframe / 子资源不再绕过 allowlist（收编 PR #229；issue #213），私网预检收窄到子域，显式列名的本地主机不再误杀。
- **不可信来源的工具结果加「数据非指令」结构定界**（收编 PR #233；issue #217）。
- **未受信项目的 `AGENTS.md` / `.rivet.md` 不再注入**（收编 PR #234；issue #218）。
- **skills/install 的 `names[]` 过文件名守卫**——路径穿越封堵（收编 PR #210；issue #207）。
- **project 路由的 cwd 必须在册**，且统一到 realpath 判定——已授信目录不再因 `/var` 与 `/private/var` 差异被误拒（收编 PR #226；issue #221）。
- **`scratchDir` 必须落在数据根内**（收编 PR #224；issue #223）。
- **请求体 4MB 护栏**：修「unexpected end of hex escape」HTTP 400 与清洗收口。
- **全局紧急中断热键（issue #235 Wave 3）**：Rust 侧注册的系统级热键，触发即中止所有运行中会话；注册状态经 invoke 可达、中止后列表即时刷新，加速键规格钉入测试防回退。
- **桌面自动化归口（issue #235 Wave 4）**：合成键鼠 / 抢占前台统一走 `computer_use` 通道（带让出护栏与审批），不再用 shell 自造注入；shell 侧同族命令在用户活跃时跳过并告知。

## 升级注意

- **macOS 桌面端首次安装报「已损坏」**：本版 macOS 包仍是 ad-hoc 签名、未经 Apple 公证（Developer ID 证书未就位），浏览器下载的 .dmg 会被 Gatekeeper 拦截。安装后执行一次即可：
  ```bash
  xattr -cr /Applications/Tianshu.app
  ```
  经应用内**自动更新**升级的用户不受影响（更新通道不经过 Gatekeeper 隔离）。根治（Developer ID 签名 + 公证）的打包管线已就绪，见 `docs/DESKTOP-RELEASE-MAC.md`「签名 / 公证现状」。
- 本版含 MCP 连接级审批门：升级后首次连接 MCP 服务器需要一次授权确认。
- 桌面端录音引擎在 Windows 上改走本地 whisper（此前 Web Speech 后端不可达，表现为录音失败）；首次使用需确认模型已就绪。
- 自动化任务的 `stopped` 是归档终态：定义与历史保留但不再触发，如需复用请在面板「复制重建」（新任务拿新 id，旧历史留在归档组）。
