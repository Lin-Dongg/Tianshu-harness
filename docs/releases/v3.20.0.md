# v3.20.0 发布记录

> 日期：2026-09-14
> 上一版本：v3.19.0（2026-09-12）
> 性质：**功能版**——禅模式全链路上线（含桌面徽章）、Stop/打断体验对齐 Codex·Claude Code、Provider 多 key 全栈、图像生成能力、桌面性能六阶段、社区安全审计二十余项收编。

## 重点新能力

**Zen Mode 禅模式（全链路上线）**

- **读专注开局（显式开启）**：配置 `tools.zen.enabled: true` 后，会话开局主控工具面收窄到读面（read 类 + `zen_unlock` 解锁声明工具），先理解再动手——模型调用写工具或 `zen_unlock` 即晋升全量（放行语义，零往返）；8 轮步数预算到自动晋升；首消息分诊默认开（单行短消息直接跳过禅，曾试「默认关」当日回退并记录在案）。
- **TUI 可见性**：状态栏「禅」徽章（晋升即消失）；`/fast` 立即解除；`zen_unlock` 结果改 glance bar 6s 限时提示（此前常驻挂在推理区下方）。
- **桌面端徽章**：Composer 动作行呼吸点旁渲染「禅」徽章与轮数 tooltip——sidecar 建连补发 `zen_phase` 相位快照（seq=0 合成事件），长会话切走再切回徽章不丢；事件载荷与会话 record 共用同一形状并落盘，sidecar 重启后仍在。
- **相位持久化**：arm/晋升/步数计数逐轮落 meta，中途退出 resume 不清零预算（反复 resume 无限续期的漏洞两侧焊死）；worker/headless/one-shot 不 arm。
- **缓存纪律**：zenLean appendix 收敛只动 dynamic appendix，zen 关闭时工具面与字节逐项不变（哨兵锁定）；晋升的一次性前缀重建为设计内代价（实测评估见 docs/analysis）。

**Stop / 打断体验对齐 Codex·Claude Code**

- **Stop 后立刻发消息即被接受**：abort 四出口统一收尾、postSession（telemetry/memory/consolidation）进后台串行链脱离 settle 关键路径——真机实测 abort→再发从 4340ms 降到 ~12ms。
- **打断留痕**：被中止的轮次保留 user 原文 + 已流出的 partial 并追加 `[interrupted]` 标记（不再静默撤回），下一轮模型看得见自己说到哪被打断；可经 `agent.interruptMarker` / `RIVET_INTERRUPT_MARKER` 关闭。
- **桌面端配套**：发送期乐观回显（pending 气泡 FIFO 对账 + 失败回退）+ 线程内「⏹ 已中断」chip；打断后 lane flush 归并头改「上轮已被用户打断」。

**Provider 多 key 全栈（同一供应商多把 API key）**

- **keys 池数据层**：key 级凭据解析与幂等迁移（按「用户显式凭证」判据，不产生幽灵池）；keys 池移出 config.json 落独立 `provider-keys.json`——旧版 rivet 不再能抹掉 key 池；设置页加 Key 池备份提示。
- **桌面多 key UI**：供应商详情页 key 区块（添加/改名/删 key）、key 级模型管理、模型选择器按 provider×key 分组（同 wire id 模型可分别钉到指定账号）、欢迎页与默认模型下拉同步分组。
- **服务端配套**：keys CRUD 路由、按模型归属 key 解析凭据（含 headless `--model` 指到非首个 key 的模型）、current 标记精确到 key（双 key 挂同模型 id 时不再两条都标、点不动）。
- **探测链统一**：key 探测收敛进 provider-probe 共享链（超时/错误码/anthropic 头语义保留并扩展），keyless 空列表探测成为正式能力。

**图像生成（issue #8，生图模型接入）**

- **独立用途槽 `agent.imageGenModel`**：与 `agent.visionModel` 平级同构——注册一个 OpenAI 形态的文生图端点（SiliconFlow / OpenAI Images 等）即可出图；`provider.default` 与 `agent.defaultModel` 字节级不变，前缀缓存锚定不受影响。
- **`generate_image` 工具**（fail-closed）：prompt → 图片字节 → 本地文件，**只把路径写回对话**——base64 绝不进上下文、也绝不进错误文案；未配置生图槽时工具不进工具表（不产生「调了必然失败」的无效调用，不启用者工具定义逐字节不变）。生图客户端宽容解析三种响应形状，尺寸字段名可配（OpenAI `size` / SiliconFlow `image_size` 只发一个）；粘贴完整端点 URL 自动剥 `/images/generations` 尾巴。
- **设置面板三合一**：Settings → 生图模型——端点注册（Provider / Base URL / 模型 ID / Key / 尺寸字段名）、**连通性真测（真的出一张图**，按钮旁如实标注会消耗一次生成额度）、生图参数与已注册模型下拉快选；配置落盘即广播刷新存活 agent 工具表，当前会话即可用。
- **生图标记三层贯通**（M5）：probe 打标 → 服务端透出 → chat 选择器过滤——生图模型不再混进主会话列表（选中必然失败的请求），keys 池路径同判据。
- **安全纵深**：响应体 URL 过 SSRF 预检（复用 `web_fetch` 判据）；错误文案按双判据抹掉 base64；字节上限三层（估算 → 真值 → 写盘前复核，50MB）；超时覆盖到 body 读完；凭据先于配置写入（消除「config 已指向而密钥未落盘」的中间态窗口）。
- **边界**：ComfyUI 三步异步链路与 `task_id` 轮询制端点本次不支持（真测会明确报错说明原因，非静默降级）。

## 性能

- **长会话回放帧数 −78~87%**：回放出口合并已闭合 delta run 为单事件（冷开大数据量会话不再逐帧回放）。
- **全局推送通道**：ServerEventBus + GET /events SSE，sessions/tasks/health 轮询降到 30s 兜底——桌面空闲不再三路轮询。
- **启动闪屏根修（首帧到内容 3.96s→2.1s）**：平台 conf 补 `visible:false` + sidecar 启动移出主线程；同色骨架 splash + page_load 提前 show + 原生底色跟随主题。
- **sidecar 首秒**：预热延后 + 宿主探针异步预热 + /environment 首探延后 + 阶段计时落日志；常驻栏 backdrop-filter 收到 `data-backdrop` 闸门（零模糊 solid 不再为整栏建合成层）；终端面板保活 + chunk 预热（开合不再卡顿）。
- **resume 预检最大单项开销消除**：`runResumePreflightOai` 的 roundCount 改纯计数（issue #139）；requestTimeCollapse 单遍索引化，工具结果折叠 O(n²)→O(n)（收编 PR #142）。

## 安全与健壮性

- **社区安全审计二十余项收编**（zzuu080603，issue #115–#125 / PR #127–#134）：`request_path_access` 默认 read + 拒绝根/系统目录与敏感文件；`import_resource` GitHub 子路径 `..` 穿越封堵（词法 + realpath 双层）；approval-risk 中段 `..` 绕过 auto-safe 写闸修复；SSRF 白名单 IPv6 literal 方括号 / IPv4-mapped / NAT64-6to4 口径统一；MCP OAuth 回调 error 参数反射 XSS 转义；敏感文件门补齐 export/import 检测；`/cd` 换工作区后按新 cwd 重建 FileHistory/claimStore；checkpoint 创建失败不再静默置位（回滚窗丢失可见）；`saveConfig` 剥掉 profile 临时层（无关保存不再把覆盖值烘焙进全局）；config-watcher 改 watch 父目录（首次原子写后不再永久失聪）；回滚成功后 journal 写失败不再误报失败；durable claims 跨会话继承恒空修复；hash_edit/ast_edit/apply_patch 接入撤销/回溯/LSP 三处名单。
- **关停与写链健壮性**：`rivet serve` 收 SIGINT/SIGTERM 优雅关停（SSE 活动连接注册表 + closeIdleConnections + 保险丝，桌面连着时 1.5s 内退出）；claim-store 短暂文件锁梯度重试 + 会话收口排空（撞 AV/EDR 秒级锁时写链自愈，不再丢行）；会话事件写链错误分类（永久码停链 + 落诊断日志）；npm test 挂死源（claim-store 写链无限重试）根治。
- **审查假报告链治本**：探索过的 worker 不再进无历史修复通道；审查报告截断根因（报告档预算兜底 4096→16384 + 收尾轮截断透传）。
- **写工具账本三处漏收口**：回滚范围 / prewarm.invalidate / evidence 与 claim 新鲜度——hash_edit 族修改不再落在 YOLO 档 safety net 窗外。
