# v3.16.2 发布记录

> 日期：2026-09-10
> 上一版本：v3.16.1（2026-09-09）
> 性质：**模型接入版**——DeepSeek 新模型 `deepseek-flash`（1M 上下文 + 原生多模态）上架；DeepSeek 默认模型调整为 v4-flash（V4-Pro 据悉将于 9 月 14 日下线）。

## 新增

- **DeepSeek 新模型 `deepseek-flash`**（V4.1 线）：1M 上下文、384K 最大输出、**原生多模态（支持图像输入）**、定价与 v4-flash 同档。在「切换模型」列表中即可选用。

## 变更

- **DeepSeek 默认模型调整为 `deepseek-v4-flash`**：新配置 / 新连接的 DeepSeek 默认使用 v4-flash（此前为 v4-pro）。V4-Pro 据悉将于 9 月 14 日下线，仍暂在列表中可选。
- DeepSeek 预置列表三模型共存：**v4-flash（默认）**、v4-pro、**deepseek-flash**（另有视觉实验档 v4-flash-vision-exp）。

## 配置指引（重要）

- **已在用 DeepSeek 的用户**：本地模型列表是配置快照，**不会自动新增 `deepseek-flash`**。如需使用，请在 **设置 → 服务商 → DeepSeek → 添加模型**，模型 id 填 `deepseek-flash`（上下文 1000000 / 最大输出 384000，勾选「支持视觉」；添加后会自动补全其余元数据）。
- **新装 / 新连接的用户**：无需操作，预置列表已包含，默认即为 v4-flash。
- **图片识别说明**：模型声明「支持视觉」时直接原生识图（`deepseek-flash` 已声明）；未声明的模型经「识图桥」（设置 → 识图模型）生成图片描述后发送，避免多模态模型被当成纯文本模型而看不到图。

## 升级说明

从 3.15.x / 3.16.x 直接自动更新即可，无配置迁移。
